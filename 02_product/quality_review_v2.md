## 重要产品认知升级 — **拼豆图纸网格 ≠ 纯视觉参数**

拼豆制作的物理链路：
```
PinDou 图纸（数字）
  ↓
用户购买拼豆板（实物，标准 26×26 或 27×27 塑料网格）
  ↓
按图纸把豆放到拼豆板对应格子
  ↓
熨烫融合
  ↓
成品
```

**网格尺寸不对齐拼豆板 = 用户没法直接用 = 体验断裂**：
- 40×40 图纸 + 26×26 板 → 用户得拼 4 块板（27×27=4 块），但有 12 格浪费 → 算成本麻烦
- 推荐尺寸：单板 26×26 / 双板 52×52 / 三板 78×78 / 四板 104×104

这个认知缺失了一直没人 flag — Task C / Task H 调研把"网格尺寸"当成纯像素美术参数，没考虑实物板对齐。
