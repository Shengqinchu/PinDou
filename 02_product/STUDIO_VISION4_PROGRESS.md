## 执行顺序

1. 阅读附件、源图映射与线上编辑链路诊断。
2. 修复编辑／导入服务与观测能力，整理模块，隐藏停用导航。
3. 应用指定内容、拼豆流程、图片顺序、复制和装饰动效。
4. 多轮宽高／缩放／引擎验证，修正实际发现的问题。
5. 只提交本次文件，发布 Studio，核对公网与旧工具，逐项填证据。

## 已定位的问题与处理

- 重叠直接来自全局 `.form-help { margin-top: -10px }`，同时上传控件依赖透明文件输入覆盖。现已采用独立布局和真实按钮，局部错误／进度反馈不再藏在页面顶部。
- 网站编辑“保存并发布”先 PUT 再 POST，前端只在两步都成功后接收新版本；第二步失败导致客户端持有旧版本，重试产生冲突。
- 编辑错误区在长列表顶部，上传状态不在当前图片旁；用户容易看不到失败原因或不知道仍需发布。
- 现有公共分享页导入不是登录态浏览器读取；短链接目前只识别 https，流程 PDF 的 http 分享链接需要安全升级后解析。
