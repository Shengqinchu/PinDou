## 5 个核心差距（按优先级）

| # | 维度 | PinDou 当前 | 小红书标杆 | 优先级 | 责任模块 |
|---|------|------------|-----------|--------|---------|

## 根因汇总

**差距 1 是最深的**：ADR-005a 选择"纯 API 路线，不上 GPU"时已经接受了"prompt 工程上限" — gpt-image-2 训练数据偏好让它即使被 prompt 约束仍倾向输出"真实感"。修复路径：更强 negative prompt + reference style 引导，但**理论上限仍受模型偏好限制**。如果 prompt 调到极致仍不达标，可能需要 FUTURE_WORK 第 1 条触发上 GPU + IPAdapter 强约束。

**差距 2-5 是工程修复**，按 prompt 直接派 Codex 即可。

## 与 ADR / FUTURE_WORK 的关联

- **ADR-003 变现假设**：差距 1 直接威胁"AI 路径付费转化"——质量不到 9.9 元的感知，付费链路崩
- **ADR-004 冷启动**：差距 1+2 直接影响小红书种草图质量，冷启动转化崩
- **ADR-005a GPU 决策**：差距 1 如果 prompt 调优后仍不达标，触发上 GPU（FUTURE_WORK 第 1 条）
- **PRD §4.4 风格预设**：差距 2 暴露 80×100 默认尺寸太大，建议新增 40×40 Q 版默认
