# 布贴热压知识：现成布贴定制帆布包与衣服

研究日期：2026-09-27。适用项目：Pindou Puppy / 小狗拼豆铺。

用户已确认采用现成布贴进行热压定制。本文是有来源的工艺知识及门店试行建议；**尚无本店机器、布贴或底材的实测结论**。来源编号见 [SOURCES.md](SOURCES.md)，执行流程见 [PILOT_AND_SOP.md](PILOT_AND_SOP.md)。

## 1. 先建立正确的制作思路

顾客的主要体验是选择图案、组合颜色和排版；店员把已经确认的布局固定到物品上。技术是否可靠，取决于这组组合：

**布贴表面工艺＋背胶＋底材＋机器＋温度/时间/压力＋正反面加热方式＋垫材＋冷却与洗护。**

“绣章很漂亮”“背后有一层胶”“刚烫完拿不下来”都不足以证明成品耐洗。采购和测试必须识别具体组合。相同图案更换背胶或批次后，旧工艺也可能不再适用。

本文建议的首轮范围是：**已知成分、表面平整、无涂层的棉帆布袋＋常规平面刺绣热贴**。这是为了减少试样变量，不代表已决定采购这些材料。随后验证棉质 T 恤和卫衣，再考虑毛巾绣、帽子、混纺及顾客自带物品。

## 2. 术语：表面长什么样，与背面怎么固定，是两件事

### 2.1 表面工艺

| 中文 / 英文 | 识别与使用方向 | 选购时的重点 |
| --- | --- | --- |
| 刺绣布贴、绣章 / embroidered patch | 线迹构成图案，表面有纹理；适合图标、字母、轮廓清晰的图案 | 是否有稳定包边、细字是否糊、实际厚度、底布是否外露 |
| 织唛布贴 / woven patch | 图案由织造形成，通常较平；可比较其小字和细节表现 | 以实物判断细节，不把屏幕效果当成品 |
| 毛巾绣、雪尼尔章 / chenille patch | 蓬松绒面，常见字母、队服风格 | 绒面压塌、毡边、厚度差、专用保护垫及耐洗声明 |
| 立体绣 / 3D embroidered patch | 明显立体效果 | 可能需要下加热；有产品明确不适合水洗 |
| 印花布章、升华布章 / printed or sublimated patch | 图像先印在布章上，再固定到物品 | 印花面耐热性、边缘和背胶；不等同直接对衣服升华 |
| PVC、硅胶、皮革类章 | 外观和材质不同的装饰章 | 不能沿用棉布绣章的工艺，单独建档 |

厂家产品目录可用于认识这些分类，但不能据分类推断所有产品的适用面料。[S01：STAHLS’ Canada 产品分类](https://www.stahls.ca/en-ca/emblems-and-patches)

HTV（刻字膜）、DTF（膜上印刷转印）也使用热压机，但不属于本轮“现成布贴”主线。不能混用它们的揭膜、复压和洗护说明；暂时不需要因此采购打印机、刻字机或刺绣机。

### 2.2 背面固定方式

| 背面说明 | 原理与辨别 | 本店处理 |
| --- | --- | --- |
| 热熔背胶 / heat-seal、iron-on backing | 在该胶体系要求的条件下热压粘合；外观可能像薄膜 | 要到对应 SKU 的完整压烫和洗护说明 |
| 不干胶 / pressure-sensitive、stick-on | 靠压力粘贴，不能凭“粘得住”判断耐洗 | 不自动列入可水洗热压款 |
| 临时粘＋热熔双用途 | 某些产品可先粘定位，再按说明热固定 | 必须由该商品明示，不能推广到普通不干胶 |
| 无胶、缝制款 / sew-on | 需要缝合，背衬不是热熔胶 | 从热压体验选材区分开 |
| 魔术贴 / hook-and-loop | 钩面和毛面配合使用；连接到衣物的底座还需固定 | 单独考虑底座的缝合或热压要求 |

可核实的双用途例子是 Michaels 自有 Make Market 商品 10805593，页面区分临时粘贴和永久熨烫，并让使用者查看包装背面的说明。这恰好说明“有不干胶”不能简单判定为只能贴或一定能烫。[S13：商品页](https://canada.michaels.com/product/summer-tropical-flowers-ironon-adhesive-embroidered-patch-set-10805593)

供应商写“进口胶”“环保胶”“强力背胶”时，继续问具体型号、材料兼容性和工艺。名称或手摸黏性不能替代规格书。

## 3. 底材兼容性：首轮要验证什么

以下为本店试样优先级，不是全行业适用/禁用清单。

| 底材 | 首轮处理建议 | 检查重点 |
| --- | --- | --- |
| 无涂层棉帆布袋 | 优先试样 | 成分、克重、缩水、是否能把单层套上压板、袋口及手柄缝线 |
| 棉质 T 恤 | 第二组试样 | 平整、不拉伸定位；布贴大小和重量是否影响穿着 |
| 棉/涤卫衣 | 逐款确认 | 成分及颜色批次、起绒、厚度、口袋接缝、压印 |
| 牛仔布 | 可单独测试 | 接缝厚度、表面处理、掉色、胶是否贴合 |
| 涤纶、运动面料 | 需要专项测试 | 热损伤、染料迁移、弹性；“含涤”不等于全部不行 |
| 尼龙、防水或防污涂层面料 | 暂不作为默认可接品 | 胶能否粘上涂层、耐热与涂层完整性 |
| 弹力针织、罗纹、毛圈面料 | 分开评估缝制或专用体系 | 平整度、拉伸后起皱、表面是否足够接触 |
| PU/PVC 皮面、真皮、丝质、未知复合层 | 暂不开放常规热压 | 不能只看外层颜色或商品名判断耐热 |
| 帽子、厚拉链包、带衬里袋子 | 后续专项 | 曲面与接缝导致的压力不均；各层可能耐热不同 |

Emblemtek 的绣毡章说明提醒了涂层影响粘合、弹力面料可能变形、毛圈表面及帽子难以接触等问题；这些是检查方向，不是把该厂的配方移植到所有布贴。[S06：厂家应用与洗护 PDF](https://emblemtek.com/wp-content/uploads/2019/07/TekSpec-ECE-FE-Embroidered-Felt-Emblems-2023-English-1.pdf)

**底材登记要写完整**：品牌/型号、纤维成分、颜色、批次、克重及单位、洗标、涂层、可装饰区域、是否预缩、已测尺寸变化。克重表示单位面积质量，不等同布厚；仅写“帆布”不够。

从袋口把一面套上合适下板，或使用厂家认可的撑垫，使压烫面平整。垫材会改变实际压力和传热，不能临时换成任意厚毛巾后沿用旧卡。

预洗要按底材和胶的说明决定：需要预洗时先洗、完全干燥并测尺寸；不把预热几秒当成预洗或预缩的替代。不要无条件承诺所有袋子都可机洗。

## 4. 设备：先选材料体系，再定机器

| 设备 | 适合的角色 | 采购判断 |
| --- | --- | --- |
| 家用熨斗 | 厂家允许时的小样或家用操作 | 温度档位、有效接触面、操作压力与工艺可重复性要单独验证 |
| 手持小热压机 | 小区域、少量试验或补充工具 | 操作者承担施压；不假设与固定压机同温同秒就等效 |
| 平板翻盖机 | 平面帆布袋、衣物的候选主机 | 调压、温度稳定、开口空间、可否套衣、下板与维护 |
| 摇头/抽拉机 | 需要更方便排版或装载时比较 | 多占空间、机器重量、台面承重和动线 |
| 带下加热设备 | 某些厚章和立体章指定需要 | 先确认准备买的布贴确实需要，再核算投入 |
| 帽压机 | 帽子业务扩展 | 曲面压板、帽型和接缝适配；不是平板主机的替代 |

Cricut 的官方操作说明按机型和材料区分步骤；其 Heat Guide 的设置不能当作第三方刺绣布贴的通用设置。[S10：EasyPress 使用说明](https://help.cricut.com/hc/en-us/articles/360009378134-How-to-use-Cricut-EasyPress)

### 4.1 主机与辅助用品清单

- 主机：数字温控与计时、能重复设定的压力、适合排版面积的有效压面、可获得的售后与配件。
- 工作区：稳固耐热台面、冷却区、能清楚区分的顾客排版区和店员压烫区。
- 材料配套：厂家指定的保护片、硅胶/泡棉垫或下板；耐热定位胶带；尺、排版模板、镊子、除尘工具。
- 测量：厂家认可的测温条或接触式测温工具、计时核对方法、测试废料及同批次空白品。
- 记录：SKU 标签、托盘、试样卡、洗护卡和返工记录。

建议比较能覆盖预定作品排版区域的平板机，不能只看机器宣传尺寸；袋口、接缝和装载方式可能缩小可用区域。先用纸样模拟最大片布局，再选择尺寸。

### 4.2 加拿大店内采购要点

核对实际型号的电压、电流、插头、支路要求、开合净空和整机认证。STAHLS’ MAXX 页面举例显示：不同规格既有 1000 W，也有 1800 W 的选项，并要求指定支路；所以不能把所有热压机都当作能随意插入拼豆工位的设备。[S08：设备规格](https://www.stahls.ca/en-ca/maxx-clam-heat-press)

安省采购检查以 ESA 认可的整机批准标识为准，不能用某个内部零件的认证代替整机标识。插座或支路不明确时，让场地方或有资质的人员核实；本轮未检查店内电路。[S11：ESA 认可标识](https://esasafe.com/electrical-products/recognized-certification-marks/)

### 4.3 与拼豆工位的关系

可考虑共用部分尺、托盘和组织方式，但**不沿用拼豆熨烫参数**。拼豆的目标是让珠子融合；布贴的目标是让胶与纤维形成合适结合，同时保护表面装饰和底材。共享机器也要换干净保护材料，核对温度、垫材及占用时间。现有拼豆机器是否能胜任布贴，仍待型号与实测确认。

## 5. 温度与压力：怎样读参数，怎样避免照抄

### 5.1 一张可执行工艺卡必须写什么

| 项目 | 记录要求 |
| --- | --- |
| 材料 | 布贴及背胶型号、批次、尺寸、底材型号与颜色 |
| 设备 | 机器、上/下板、加热方向、下垫和保护层 |
| 温度 | 明确 °C 或 °F；上板/下板分别记；设定值与测量值分开 |
| 时间 | 预热、主压、翻面压、复压逐项列出；没有的步骤写无 |
| 压力 | 厂家术语及本机如何复现，例如机器显示/旋钮基准/垫层厚度 |
| 冷却与揭离 | 是否有离型纸、何时揭、冷却到何种状态；不要把胶膜当纸剥掉 |
| 洗护 | 首洗间隔、洗涤和干燥条件、是否允许缝制 |
| 验证 | 试样照片、冷却后检查、洗涤结果、批准范围 |

“中压”不是跨机器的统一数值；气动机进气表的 PSI/bar 也不能直接理解成布贴表面压强。没有转换依据时，不把手拧调压旋钮编成一个精确 bar 值。

换算：`°C = (°F − 32) × 5 ÷ 9`。温度、时间、压力都不能相互无限补偿；升温救不了错误背胶，也可能先损坏面料。

### 5.2 厂家实例：仅适用于表中产品和流程

| 指定产品与设备方式 | 查到的说明要点 | 对本店的启发 |
| --- | --- | --- |
| STAHLS’ Premium Embroidered，只有上板加热 | 360°F（约 182°C）、21 秒、中偏实压力；先预热下板 60 秒和底材 20 秒；指定硅胶或 1/8 英寸泡棉保护层 | 不能只截取温度与主压秒数 |
| STAHLS’ Premium Embroidered，上下加热 | 上 280°F（约 138°C）/下 320°F（160°C），30–45 秒，中偏实压力，指定保护层 | 与上一行是两种方案，不是连续两道工序 |
| Falcon Iron-on Backing Embroidered | 去离型纸并用耐热胶带定位；翻到布贴朝下，经衣物背面压；325°F（约 163°C）、15 秒，稳定实压，完全冷却后处理 | 正反面和背胶不同，会产生不同工艺 |
| STAHLS’ 3D Embroidered | 厂家要求上下同时加热，并明确不用于需要水洗或干洗的物品 | 不适合直接纳入常规可洗衣服套餐 |

来源：[S02：Premium Embroidered](https://www.stahls.ca/en-ca/embroidered-patches)、[S05：Falcon](https://falcontransfers.ca/pages/patch-instructions)、[S04：3D Embroidered](https://www.stahls.ca/en-ca/3d-embroidered-patches)。**没有购买并确认这些产品时，表中不是机器操作处方。**

发现一个资料冲突：STAHLS’ Chenille 页面规格区写 50 次水洗，洗护段却写至少 25 次。已登记为待厂家澄清；不能任取一个数字宣传，更不能转用到无牌毛巾绣。[S03：同页冲突](https://www.stahls.ca/en-ca/chenille-patches)

### 5.3 机器读数正常也可能压不牢

检查加热面中间与边角的均匀性，以及压力是否均匀。STAHLS’ 测试资料使用多点测温条和四角纸张检查；纸张阻力只能帮助发现不均匀，不能给出绝对压力。[S07：热压机测试说明](https://assets.stahls.com/stahls/content/pdf/techsheets/Heat_Seal_Machine_Test_Kit.pdf)

## 6. 排版与制作：作品效果也要可复制

以下为门店建议，需用试营业反馈调整。

- 给顾客实物大小的排版范围，标出袋口、口袋、拉链和接缝不可压区域。
- 提供三个起步构图：一个主图＋少量小图；字母姓名＋主题图；留白较多的角落图案。顾客可自由组合。
- 把作品拿起或套到展示板上检查阅读方向，名字和字母顺序由顾客确认。
- 不默认叠贴。下面一层是否能承受再次加热、上层胶是否能粘在绣线上，都需要额外测试。
- 同次压制优先使用同一已验证工艺组。不同厚度布贴混排时，凸起的大章可能影响小章受压。
- 定位后拍一张布局照片，记录 SKU 和数量；实际压制前再次核对。保留作品照片即可，不必额外收集顾客身份信息。
- 布贴的购买尺寸、商品图片尺寸和成品可用布局分开描述；不要仅靠效果图承诺每张图的精细程度。

现场完整流程在 [SOP](PILOT_AND_SOP.md) 中，默认由店员操作热压机。客人选择、排版、确认与等待冷却的动线，要与高温区域分开。

## 7. 常见失败：先排因，再决定返工

| 现象 | 先检查 | 处理方向 |
| --- | --- | --- |
| 整片松脱 | 是否买成缝制/不干胶；离型纸是否正确处理；材料兼容性；机器温度 | 确认胶与说明，再在废料试；不直接加到最高温 |
| 边缘翘、中间粘 | 接缝撑高、下板覆盖、厚薄差、边角温差 | 调整承托、单独验证小区域；按厂家范围返工 |
| 热的时候牢，洗后掉 | 首洗条件、胶/布兼容性、批次、实际工艺 | 暂停对应组合，复测；不能以第一次表面粘合代替耐洗 |
| 布发亮、黄变、出现压板框 | 面料耐热、压力、压板边缘、覆盖材料 | 停止该组合；更换兼容材料或在厂家允许范围调整 |
| 毛巾绣/立体章压扁 | 热从哪面进、保护垫、压力 | 换指定垫材或指定加热方式，不用更高压力补救 |
| 白图被染色 | 深色涤纶或升华底材、批次 | 留样观察，验证阻隔体系或改底材；延迟出现也要记 |
| 布面起皱、字母歪 | 排版时是否拉伸、预缩差异、搬动 | 不拉伸布料；确认尺寸与定位方法；重做样品验证 |
| 胶溢出、粘到另一层 | 胶量、叠层、压力、隔离与套板方式 | 停止反复压，调整工艺；别对顾客衣物随意用溶剂 |
| 局部粘、局部不粘 | 温度/压力分布、绣章厚度、接触面积 | 检查设备和平整度，不先归因顾客操作 |

接缝、拉链、纽扣妨碍接触的排查依据见 [S09：Cricut 故障说明](https://help.cricut.com/hc/en-us/articles/42141017622807-Troubleshooting-heat-transfer-results)。其追加热压秒数属于自身材料指导，本店不套用。

染料迁移可能延迟出现；把“隔天/数日后再观察”加入试样是本店建议，不代表观察几天即可保证永不迁移。相关机理来自厂家对涤纶热转印的说明，具体布贴是否出现仍待验证。[S18：STAHLS’ 染料迁移说明](https://blog.stahls.com/dye-migration-is-for-the-birds/?amp=1)

## 8. 洗护与耐用性

成品洗护取 **底材、布贴、背胶三者可接受条件的交集**。如果布贴能机洗但袋子的洗标不允许，不能给整只袋子承诺可机洗。

- 首洗间隔：按该 SKU 的书面说明填写；未知就向供应商核对，不把所有热贴统一写成 24 或 48 小时。
- 洗涤温度、翻面、洗衣袋、洗涤剂、漂白、干洗和烘干均需确认；“冷水轻柔洗、自然晾干”也要与底材相容。
- 可洗次数属于具体厂商测试条件下的声明；本店 5 次样品测试不能升级为 50 次耐洗认证。
- 翘边时让顾客联系门店并提供局部照片，不要求其自行无限加热。
- 缝边可以是另一种经确认的固定方案，但不是所有胶都允许穿针。HeatnBond UltraHold for Dark Fabrics 官方特别说明不应缝制；这个反例不能误解为所有布贴都不能缝。[S12：Therm O Web 产品说明](https://www.thermoweb.com/blogs/blog/pirate-halloween-shirts-with-heatnbond-for-dark-fabrics)

## 9. 以后常见问题的快速答案

| 问题 | 回答方向 |
| --- | --- |
| 能不能用拼豆那个熨斗？ | 先看机型和布贴说明，再试相同材料组合；原来的烫豆经验不等于布贴验证 |
| 有胶的都可以直接烫吗？ | 不一定，区分热熔、不干胶、双用途和无胶背衬 |
| 到底设多少度、多少秒？ | 查实际 SKU 工艺卡；没有卡就先找供应商说明，不能套本文其他品牌案例 |
| 用高温多烫一会儿是不是更牢？ | 不能这样保证；可能损伤面料、压塌纹理或影响胶层 |
| 衣服和帆布包用同一设置吗？ | 只有两种底材分别验证后才可共用 |
| 可以洗吗？ | 查整件成品的洗护交集与样品结果；看起来像绣章不代表耐洗 |
| 能带自己的包来做吗？ | 先验成分、洗标、涂层和结构；首轮建议只开放已验证的店内空白品 |
| 帽子能一起做吗？ | 作为独立工艺；曲面、缝线与设备适配要先验证 |
| 买布贴还要再涂胶吗？ | 已配热熔胶的成品按原说明操作；随意叠胶会改变工艺 |
| 普通布胶/热熔胶枪能替代吗？ | 不作为本店可洗热压产品的默认方案；胶黏工艺须另测 |
| 要买刺绣机吗？ | 当前是采购现成布贴的组合体验，主线不需要自行刺绣 |
| 能烫错后拆掉重来吗？ | 不承诺无痕移除；先在样品验证，成品排版需在压烫前确认 |
| 能一次压很多片吗？ | 看是否同工艺、同受压条件和完整覆盖；不能仅按数量判断 |
| 做起来很快，为什么要算人工？ | 选材指导、确认、装载、翻面、冷却、检查和返工都占用时间 |

## 10. 下一步落地顺序

1. 记录现有机器型号、可用工作台及店内条件。
2. 向候选供应商拿具体背胶说明与同批次样品，选两种底材做对照。
3. 用 [测试卡](templates/PATCH_TEST_CARD.md) 执行首轮压烫、冷却与洗涤测试。
4. 只把通过组合写成现场工艺卡，再试跑少人数体验。
5. 有实际耗时、损耗和采购成本后，再决定套餐、售价和对外洗护文案。
