# 布贴采购与经营准备

更新：2026-09-27。已确认方向：现成布贴＋热压定制；所在地：Hamilton。

本文包含供货线索、公开案例和内部试行方案。**尚未向商家发送询价、下单或确认库存。** 市场案例只说明存在这种经营方式，不证明 Hamilton 的需求规模或本店的可实现利润。

## 1. 采购顺序

1. 拿到布贴完整工艺和样品，初选底材。
2. 核对现有机器；如需新设备，让候选设备商确认能执行拟用布贴的流程。
3. 试出可复现组合，再建立常卖 SKU 和备货量。
4. 最后扩大图案库、底材颜色及特殊工艺。不要先把几百种不同背胶混在一个选材墙上。

起步图案库建议优先覆盖：字母/数字、小图标、动植物、爱心/星形、少量较大主图。首轮可试 20–30 个设计，数量只是控制库存的建议，是否扩展以顾客选择记录决定。需要定制 Pindou Puppy 品牌图案时，另做授权素材和打样流程。

字母不要只买等量 A–Z 套装。记录实际名字中每个字母的消耗，再按使用率补货；一种颜色断掉关键字母，会影响整套名字服务。

## 4. 进货、库存与批次

建议使用三个关联记录：

| 记录 | 最少字段 |
| --- | --- |
| 布贴 SKU | 自编编号、设计/颜色、尺寸、工艺、背胶型号、供应商、批次、成本、库存、补货周期 |
| 空白品 SKU | 型号、颜色、尺寸、成分、克重及单位、洗标、涂层、供应商、批次 |
| 已验证组合 | 两边 SKU/批次、设备、工艺卡版本、测试结果、洗护卡、是否允许销售 |

收货抽查：款式数量、尺寸、边缘线头、污渍、颜色、背胶完整性及与样品的一致性。留同批样。外观相同的新背胶或新供应商视为新组合，不能自动继承旧测试。

储存按实际材料的说明，避开热压机和潮湿区域，保留批次标签。不要把不同批次散贴全部倒进一个盒子后失去追溯。陈列样、顾客排版用样、可销售库存可以分开，减少手摸背胶带来的污染。

## 7. 成本怎么计算

所有正式成本统一为 CAD，并记录报价日期和汇率来源。以下是算式，不是供应商报价。

```text
单个材料到店成本
  = (采购价 + 分摊运费 + 清关/其他不可抵扣成本) / 实际可用数量

单件可变成本
  = 空白品 + 各布贴数量×到店单价 + 消耗品
    + 店员实际分钟/60×人工小时成本
    + 生产报废/返工准备 + 支付费用

单件贡献
  = 不含代收销售税的收入 - 单件可变成本
```

进货坏品损耗若已通过“实际可用数量”计入到店价，就不要重复加一次；制作返工是另一类损耗。店员本人操作也要记录工时，不当作零成本。贡献额尚要覆盖房租、设备和其他固定费用，不等于净利润。

### 仅演示算式的假设例子

| 假设输入 | CAD |
| --- | ---: |
| 空白袋 | 5.00 |
| 4 片布贴，每片 0.80 | 3.20 |
| 消耗品 | 0.60 |
| 8 分钟人工，按 24/小时 | 3.20 |
| 生产报废/返工准备 | 0.50 |
| 上述小计 | 12.50 |
| 假设税前售价 30，支付费假设为 3%＋0.30 | 1.20 |
| 单件贡献：30−12.50−1.20 | 16.30 |

表中工资、费率、材料价与售价全部是演算输入，**不是本店实际数据，也不是建议售价**。实际决策应以试样和询价替换。

## 8. 产能与排队

```text
每件压烫工位占用时间
  = 装载 + 对位核查 + 必要预热 + 各次压烫 + 翻面/重新定位 + 卸件

设备理论件数/小时 = 60 / 平均每件工位占用分钟
实际产能取设备、店员工时、冷却/检查区域中最紧的限制
```

例如工位每件占用 3 分钟，则理论 20 件/小时；这不包含指导、突发返工和休息，所以不能直接卖 20 人的整点预约。一轮 6 人同时完成排版，若均需该工位 3 分钟，最后一件完成压烫约需 18 分钟，还未计冷却与检查。

不同温度工艺换组也占时间；把同工艺组合分批处理，同时保持每位顾客作品、SKU 和排版照片对应。与拼豆共用店员/机器时，先记录两种业务的高峰冲突，再决定加设备或限制场次。
