# Compliance Checklist

> 调研日期：2026-05-24  
> 口径：产品与上线准备视角，不构成法律意见；小程序提审、算法备案、跨境数据等重大决策上线前应咨询律师 / 合规顾问。  
> 当前主体决策：个人主体小程序（ADR-006）；当前服务器设想：日本腾讯云（FUTURE_WORK 第 2 条）。

## 三个关键问题的明确回答

### 1. 个人主体能否做 AIGC 类小程序？

**结论：不建议按个人主体直接上线 AIGC 生成服务；完整商业化路径基本需要升级到个体工商户 / 企业主体。**

依据链：

- 《生成式人工智能服务管理暂行办法》适用于向中国境内公众提供生成文本、图片、音频、视频等内容的服务；其定义中的“提供者”包括组织、个人。
- 但提供者需要承担网络信息安全、个人信息保护、生成内容标识、投诉举报、违法内容处置、安全评估 / 算法备案等义务。
- 微信小程序侧，个人主体还会受类目、支付、广告、AIGC/内容安全材料等平台要求限制。即使法律文本没有直接写“个人不能做”，实操上也不应把个人主体作为正式商业 AIGC 上线方案。

建议：Phase 0/1 可用个人主体做非公开内测或纯图片处理工具验证；Phase 3 提审前，如保留 AI 风格化，应把“升级个体工商户 / 企业主体 + 算法备案 / 内容审核方案”列为上线前置。

### 2. 日本服务器存中国用户人像是否需要标准合同备案？

**结论：若中国用户上传的人像在日本服务器落盘 / 处理，应按“向境外提供个人信息”处理；对可识别人像按高风险个人信息保守处理，通常至少要满足告知、单独同意、个人信息保护影响评估。是否必须标准合同 / 认证 / 安全评估取决于数量与是否属于敏感个人信息。**

判断：

- 《个人信息保护法》第 28 条规定，敏感个人信息包括生物识别等信息；人像照片本身不必然等于生物识别信息，但 PinDou 的核心场景是人像 / 宠物 / 情侣照，涉及可识别自然人，建议按敏感或准敏感高风险处理。
- 《促进和规范数据跨境流动规定》第 5 条的“10 万人以下免机制”明确不包含敏感个人信息。
- 非关键信息基础设施运营者向境外提供不满 1 万人敏感个人信息的，应依法订立个人信息出境标准合同或通过个人信息保护认证；达到 1 万人以上敏感个人信息，需申报数据出境安全评估。

建议：MVP 尽量改成“国内服务器 / 图片不落盘 / 处理后短期自动删除”。若继续日本服务器，应在 Phase 2 末做跨境专项，不要等提审时再补。

### 3. MARD / COCO 品牌名能否在产品中使用？

**结论：可以谨慎作描述性使用，例如“支持 MARD / COCO 色号匹配”“导出 COCO 色号对照”，但不能让用户误以为 PinDou 与品牌方存在授权、合作、官方关系。**

边界：

- 可用：说明兼容 / 支持 / 色号对照；不使用品牌 Logo；不在产品名、域名、图标、宣传主视觉中突出品牌。
- 不建议：`MARD 官方生成器`、`COCO 授权图纸`、把品牌名作为主要卖点标题或广告关键词。
- 上线前：检查商标注册类别，必要时在产品页加“品牌归其权利人所有，PinDou 仅作色号兼容说明”。

## 上线必须满足的条件（按 Phase）

### Phase 1（PRD 阶段）

- [ ] 明确主体路线：个人主体仅用于内测 / 工具验证；商业化 AI 上线前触发主体升级评估。
- [ ] 用户协议草稿：包含上传图片授权、生成图使用、禁止违法内容、删除权、投诉入口。
- [ ] 隐私政策草稿：列明收集项、处理目的、保存期限、服务器位置、第三方 API provider、退出与删除机制。
- [ ] 敏感个人信息单独同意：对人像 / 可能识别自然人的照片单独弹窗说明。
- [ ] AIGC 服务说明：AI 生成内容标识、模型 provider、用户责任、内容安全机制。
- [ ] 商标使用规范：MARD / COCO 仅作兼容描述，不使用官方 Logo。

### Phase 2（开发阶段）

- [ ] 上传前内容审核：涉政、色情、暴恐、未成年人风险、真人敏感图过滤。
- [ ] 生成后内容审核：生成图同样走审核，失败走 fallback 或人工提示。
- [ ] 图片存储策略：默认不永久保存；生成完成后自动删除原图；用户作品集只保存用户主动确认的结果图。
- [ ] 删除接口：用户可删除作品、原图、生成图；后台保留删除日志。
- [ ] 访问控制：图片 URL 加鉴权或短期签名，禁止裸目录公开。
- [ ] 跨境方案：若继续日本服务器，准备 PIA、单独同意、标准合同 / 认证路径；优先评估国内服务器。
- [ ] Provider 抽象：保留国产合规 provider 作为主通道候选，反代只作研发 / 备份。

### Phase 3（提审前）

- [ ] 小程序备案与服务类目最终确认。
- [ ] 若使用中国大陆服务器 / 域名，完成 ICP / 小程序备案；若使用境外服务器，仍需确认微信平台域名与小程序备案要求。
- [ ] AIGC 标识：生成图页面明确“AI 生成 / AI 辅助”，必要时嵌入显式或隐式标识。
- [ ] 算法备案 / 安全评估判断：如服务具有舆论属性或社会动员能力，按规定做安全评估和算法备案。
- [ ] 内容安全、投诉举报、用户协议、隐私政策、客服邮箱全部可访问。
- [ ] 支付 / 广告：个人主体下不把微信支付、激励视频作为提审依赖；需要商业化时升级主体。

## 六个维度

### 维度 1：用户人像上传的隐私合规

要求：

- 上传图、生成图、处理日志都属于个人信息处理活动；可识别人像应按高风险处理。
- 处理敏感个人信息需要特定目的、充分必要性、严格保护措施、单独同意，并额外告知必要性及影响。
- 保存期限必须最短必要；处理目的完成后应删除或停止处理。
- 需要提供查阅、复制、更正、删除、撤回同意、投诉处理入口。

产品动作：

- 上传页增加单独勾选：“我同意上传图片用于生成拼豆图纸；如图片包含本人 / 他人肖像，我已获得授权。”
- 隐私政策写清：原图默认仅用于生成，保存不超过 N 天；作品集需用户主动保存。
- 后台加定时删除任务：原图 / AI 中间图 / 失败任务文件到期删除。

### 维度 2：ICP 备案 + 小程序类目

要求：

- 非经营性互联网信息服务需要备案；小程序也属于移动互联网应用程序备案范围。
- 服务类目以微信后台当期可选项为准，工具 / 图片处理是可能方向，但 AIGC、支付、广告会提高审核门槛。
- 个人主体类目、能力、支付、广告限制较多。

建议：

- Phase 3 前用微信后台实际新建小程序确认可选类目，不靠二手表格拍板。
- 如果产品定位仍是“AI 生成图纸”，不要试图伪装成纯工具类目过审；可在 PRD 中拆成“基础图片处理”和“AI 高级风格化”两条审核路径。

### 维度 3：AIGC 内容审核 + 算法备案

要求：

- 向境内公众提供图片生成服务适用生成式 AI 暂行办法。
- Provider 需要合法数据 / 基础模型来源，不得侵害个人信息、肖像权、知识产权。
- 提供者需对生成内容标识，处理违法内容，提供投诉举报。
- 具有舆论属性或社会动员能力的生成式 AI 服务，需要安全评估和算法备案。

建议：

- 反代 `gpt-image-2` 可用于研发 PoC；生产上线优先评估火山 / 通义等国产合规 provider。
- UI 明示“AI 辅助生成拼豆图纸，不保证完全还原本人”；生成结果页加 AI 标识。
- 审核失败时 fallback 到普通量化，不向用户暴露 provider 报错。

### 维度 4：商标边界

要求：

- 商标法允许对商品通用名称、型号、功能、用途等作正当描述性使用，但不能造成来源混淆。
- 商标侵权判断看是否作为商标使用、是否导致相关公众混淆。

建议文案：

- 可用：“支持 MARD / COCO 色号匹配”“导出 MARD 与 COCO 近似色对照”。
- 避免：“官方”“授权”“联名”“旗舰”“MARD 拼豆生成器”。
- 页脚声明：“MARD、COCO 等品牌名称归其权利人所有，PinDou 仅作色号兼容说明。”

### 维度 5：小程序提审常见拒审点

高风险点：

- 类目不匹配：实际 AI 生成却报纯工具。
- 无隐私政策 / 用户协议 / 删除入口。
- 上传图片和生成图未做内容审核。
- AI 生成内容未标识，容易被认为误导用户。
- 个人主体承载支付、广告、AIGC 类目能力不足。
- 使用境外模型 / 境外服务器但未说明个人信息跨境处理。

提审材料建议：

- 一页“算法服务说明”：输入、处理、输出、审核、删除、投诉。
- 一页“隐私与图片处理说明”：存储位置、期限、删除机制。
- 一页“内容安全说明”：上传图审核、生成图审核、违规处置。

### 维度 6：小红书 / 微信生态引流合规

要求：

- 小红书对站外交易导流持续治理；平台官方商业合作路径是蒲公英 / 专业号 / 店铺 / 合规组件。
- 微信生态内也不能通过诱导分享、违规外链、规避平台交易规则来获客。

建议：

- 小红书内容先做“作品展示 + 教程 + 参数分享”，不写微信号、二维码、站外支付暗语。
- CTA 用“评论想看尺寸 / 色卡”“收藏参数”“关注后续案例”。
- 若需要交易，优先走小红书店铺 / 官方留资组件 / 小程序合规入口，等 Task F 复核后再定。

## 高风险条目

| 风险 | 等级 | 当前应对 |
|------|------|----------|
| 日本服务器处理中国用户人像 | 高 | Phase 2 末专项处理；优先迁国内或图片不落盘 |
| 个人主体上线 AIGC + 支付 / 广告 | 高 | 内测可用个人主体；商业上线触发个体 / 企业升级 |
| 反代境外模型生产使用 | 高 | PoC 可用；生产优先国产合规 provider，保留 fallback |
| 上传 / 生成图内容审核缺失 | 高 | Phase 2 必接审核；审核失败降级普通量化 |
| MARD / COCO 品牌混淆 | 中 | 只作兼容描述，不用 Logo，不写官方 / 授权 |
| 小红书站外导流 | 中高 | 只做合规内容种草，交易路径等官方组件确认 |
