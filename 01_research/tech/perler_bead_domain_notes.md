# 拼豆领域知识补充

> 目的：把 Task C 从“图像风格化 + 量化”补齐到真实拼豆商品流程。当前结论用于指导 prompt、量化、成品预览和后续图纸导出。

## 1. 基础概念

拼豆 / fuse beads / iron beads 的核心不是普通像素画，而是“每个格子对应一颗实物豆”。真实交付要同时满足：

- 视觉上好看：用户先看成品预览，判断像不像、好不好看、值不值得买。
- 制作上可行：每个格子有确定品牌色号、数量、坐标和分区图。
- 尺寸上合理：格数越多越清晰，但颗粒数、成品尺寸、制作难度和成本都会上升。

## 2. 尺寸与品牌

| 类型 | 常见直径 | 适合用途 | 对产品的含义 |
|------|----------|----------|--------------|
| Mini / 小豆 | 2.5-2.6 mm | 细节多、小成品、头像、人像 | 同样格数下成品更小；适合情侣 / 人像，但更难拼 |
| Midi / 中豆 | 5 mm | 常见手作、摆件、入门图纸 | 最通用；60x80 已接近 30x40 cm，双人像会偏大 |
| Maxi / 大豆 | 10 mm | 低龄儿童、大块图案 | 不适合精细人像 |

对 PinDou 的 Phase 1 建议：

- 默认规格先按 **MARD 5mm 中豆** 做，因为国内用户认知和供应更顺。
- 人像 / 情侣成品展示可以先给 **60x80、80x100、100x120** 三档预览。
- 如果用户追求小尺寸细节，Phase 2 再支持 2.5/2.6mm 小豆。

## 3. 成品预览和图纸不是一回事

### 成品预览图

给用户看的“购买冲动图”。它应该像真实拼好的拼豆：

- 一颗颗圆豆 / 或像素格组成。
- 有明确黑色轮廓。
- 背景通常不算豆子，除非用户选择铺底色。
- 色数少、结构清楚、远看能认出主体。

### 制作图纸

给用户实际照着拼：

- 高清网格图，每一格对应一个色号。
- 每个颜色的品牌色号 / 颜色名。
- 每色需要多少颗，建议额外加 5%-10% 备用。
- 坐标表或 Excel：第几行第几列是什么颜色。
- 大图要拆分区，例如 10x10 / 20x20 一块。
- PDF 要支持打印，最好能接近 1:1 贴在透明底板下。

所以 AI 不应该直接负责“严肃图纸”。AI 负责生成干净、可拼豆化的成品造型；程序负责确定性量化、计数、网格和 PDF/Excel。

## 4. Prompt 必须约束的拼豆规则

### 人像 / 情侣 Q 版

必须先锁住原图结构：

- 不新增原图没有的身体部位。
- 半身照保持半身，没看到脚就不能生成脚。
- 不改变人数，不新增宠物、道具、文字、logo。
- 保留发型、眼镜、帽子、衣服颜色、花束等身份锚点。

然后再做拼豆友好化：

- 大色块，少阴影，少渐变。
- 粗黑边，但黑边厚度不要吞掉五官。
- 五官要夸张但简单：眼睛、眉毛、嘴巴足够表达即可。
- 背景干净，最好输出白底 / 透明感；后处理时背景不计入豆子。
- 限制色数目标：成品预览 12-18 色，复杂人像最多 24 色。

### 宠物 / 卡通

- 保留轮廓和最有识别度的局部：耳朵、眼睛、鼻子、斑纹、配饰。
- 宠物比人像更适合低格数，因为身份判断更依赖轮廓和色块。
- 水印图只能作为风格参考；不要去掉第三方水印后复用原图。

## 5. 推荐处理流程

```text
用户上传图
  -> 权限 / 隐私检查：真人授权、车牌 / 水印 / logo 风险
  -> 主体裁切：保留关键人物 / 宠物，去掉杂乱背景
  -> AI Q版 / 卡通化：输出干净平涂图，不直接输出严肃图纸
  -> 主体 mask：背景不计入豆子
  -> 按目标格数缩放：如 60x80 / 80x100
  -> 按 MARD 色卡量化：CIEDE2000 + 色数上限
  -> 后处理：去孤点、合并小色块、保护黑色轮廓
  -> 成品预览：圆豆效果图
  -> 图纸导出：网格、色号、数量、坐标、PDF/Excel
```

## 6. 关键工程启发

- 当前 `100x100` 统一规格不够产品化。应根据主体比例自动给出 `60x80`、`80x100` 等候选规格。
- 白底不能直接变成白色豆子铺满，应有 `transparent / no bead` 状态。
- 量化后需要“拼豆后处理”，不是只靠 K-means：去孤点、轮廓保护、局部多数滤波、色数预算。
- Prompt 里不要只写 `chibi big head small body`，否则模型会补脚、补腿、补完整身体。
- 对人像，先追求 Q 版“像”和“可爱”，再追求图纸；写实路线对低格数很不友好。

## 7. 阶段建议

Phase 1 应先交付：

- 上传照片 -> Q 版成品预览。
- 2-3 个规格预览：小 / 中 / 大。
- MARD 色号数量表。
- 简单网格图。

Phase 2 再增强：

- PDF / Excel 图纸。
- 2.6mm 小豆规格。
- 多品牌色卡转换。
- 用户选择“好看版 / 好拼版”。
- 分区打印和购物清单。
