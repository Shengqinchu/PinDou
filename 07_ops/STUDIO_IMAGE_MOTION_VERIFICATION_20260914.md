# 商品图片加载与栏目入场动效

用户授权（2026-09-14）：其他 tab 与首页动效融合；图片问题“去测试和部署”。继承商品原图、全系列图文、CAD 价格、预约与后台编辑要求。

## 方案和边界

使用现有 Pillow 生成 320 / 480 / 800 px 三档 WebP 预览，quality 85，保留完整构图、透明度、方向及适用的颜色配置。公开路径 `/studio-api/media/previews/v1/{width}/{original-name}`；源图片、商品关联和数据库内容不改。缓存以原文件 SHA256、处理版本和尺寸区分，长期 `immutable`。更新上传后产生新地址，不要求客人清空旧缓存。

234 张上传商品封面在切换版本前生成 702 张派生图；已有的 6 张不同静态封面保持原地址。后续新上传图首次请求时生成，编码并发最多 2；失败时列表回退原图，业务不依赖图片转换服务。详情仍显示原图，后台上传和单个/批量编辑沿用现有入口。

列表根据实际卡片宽度与设备像素密度选择预览，接近视区 180 px 才发起请求。优先前两张；空闲时预读下一个系列前 4 张，鼠标/键盘意图出现后最多扩至 8 张。并发最多 2，成功预读最多 512 KiB；当前图片未完成、页面隐藏、省流模式或 2G/3G 时不启动预读。交互/目的系列改变时中断旧工作。已发出的请求在取消前可能仍产生少量传输，512 KiB 不是运营商计费的硬限制。没有一次预载全目录，也没有加入 service worker。

现有 Cloudflare 图像转换入口测试为 404，因此本次采用已验证的本地方案及原有 CDN 缓存，没有注册/购买额外 SaaS。候选依据见 [GitHub 与 SaaS 调研](../01_research/STUDIO_IMAGE_SOLUTIONS_GITHUB_SAAS_20260914.md)。

首页保留原有品牌叙事；预约、小店、日记、到店信息与图纸工具入口统一标题 850 ms / 18 px 的轻入场，辅助导航稍后进入。表格、表单和列表只原位淡入；图纸工作区继续自身的就绪动画。直接打开链接、站内导航都触发；分类、搜索、购物车查询参数变化不重播，不用动画阻挡操作。共享 full / reduced / system 偏好保持，减少动态或离开页面时撤销动画样式。

## 可重复实测

基线为哈希核对过的线上 `20260914013422-studio-v7` 构建；优化版使用同一公开目录和原图。两个本地站点使用同一 HTTP/1.1 服务实现及同一 FastAPI 图片服务。Chromium，1440 × 1000，DPR 1，模拟 8 Mbps 下载、150 ms 延迟；关闭动效以隔离图片加载，JS/字体先就绪，再测切到 B 系列后可见 8 张图片解码完成，每组独立冷缓存 3 次。

| 场景 | 中位时间 | 三次范围 | 8 张实际图像字节 |
|---|---:|---:|---:|
| 旧版原图与原生懒加载 | 1,528 ms | 1,432–1,713 ms | 711,330 |
| 新版预览与视区加载，无预读 | 591 ms | 545–592 ms | 214,728 |
| 新版，停留并预读后点击 | 21 ms | 21–64 ms | 214,728，点击后传输为 0 |

可见图片体积减少 **69.8%**；未预读切换时间减少 **61.3%**。预读组在点击前停留约 2.55 秒，21 ms 不是第一次访问的总加载时间。所有数字是受控本地浏览器实验，不是加拿大手机真实网络保证，也不是不同 CDN 厂商之间的测速。

全部 234 张上传封面：原图 19,199,347 B；320 档 5,789,378 B（减少 69.8%），480 档 9,378,704 B（减少 51.2%），800 档 16,810,122 B。来源图和预览文件独立，列表节省流量不牺牲详情原图。

## 验证

- `npm run build`：文案合同 78 个模块、TypeScript 和 Vite 通过，无文案批准文件变化。
- 后端 90 项通过：原图一致、预览完整比例/透明度/方向、并发原子写入、缓存头与 MIME、错误不缓存、无任意源/尺寸、编码忙碌回退，以及内容、商品和订单回归。
- Chromium / WebKit：六个主入口实际动画中间帧、站内导航、减少动态、分类/购物车不重播、DOM 与搜索保留、320/390/1440 布局、3× 密度、延迟加载、原图详情、缓存再访、503 回退、省流模式。
- 动画中途点击购物车：约 10 / 52 ms 即打开，两引擎快速导航和连续切系列正常。
- 一次独立本地后台上传/发布替换：新预览自动显示、旧缓存仍可读、原上传字节保留。
- 公网缓存检查区分“之前可见的图”和新进入预取边界的其他图；后者仍允许第一次传输，不算缓存失效。发现并修正已缓存图片仍播放 160 ms 淡入的短暂留白；最终版本对已看过/预读过的图直接显示，检查实际不透明度及 transition，而非只判断下载完成。
- WebKit 还会对无 src 的懒加载占位图派发 error；曾使尚未发起请求的图错误地启用原图回退。最终版本只处理当前源已完成的真实失败，忽略空源/旧源/仍在进行的请求。两浏览器复现空源 error 后滚入视区，仍使用预览；真实 503 仍回退原图。网络主动取消按确切 URL 与观察到的取消事件单列，不放过未对应取消的错误。
- 原有风景商品专项：两引擎规格、CAD 83 → 50 → 83 购物车、原图、多尺寸与后台价格编辑通过。测试订单仅在一次性本地数据库创建。

详细输入、截图、JSON、JUnit 结果与基线文件在 `artifacts/image-delivery-20260914/`。已有研究入口见 [原始加载评估](../01_research/STUDIO_SHOP_IMAGE_PERFORMANCE_20260914.md)。
