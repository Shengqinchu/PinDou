# 小红书导入修复 · 2026-09-12

授权：店主提供同一笔记的长、短链接，排查确认服务器拿到的是登录页面后，明确要求“修改、上线、修复”。

## 最终实现

原有 urllib 读取成功时继续使用；遇到无法取得文章的页面时，增加 `curl_cffi` 的 Chrome 兼容 TLS/HTTP 读取。每次读取使用独立短期会话，不复制用户 cookies，不运行页面 JavaScript。继续由同一解析器检查原始笔记 ID、店主作者 ID、标题、正文、时间及全部图片，保留现有原图下载、重复保护、进度恢复和草稿流程。

服务器系统 DNS 能正常解析，但内置 curl DNS 实测超时。备用通道使用系统解析所得的公网 IPv4 地址，保持原始 HTTPS 域名、SNI 与证书校验。每一步重定向仍重新检查允许的域名和公网地址；最多 5 跳、单次请求 20 秒、正文最多 3 MB。登录或验证页面明确报错，不建不完整草稿。失败日志补充异常类型，不记录链接令牌或用户正文。

复用开源组件：[curl_cffi 官方仓库](https://github.com/lexiforest/curl_cffi)。运行依赖固定为 `curl_cffi==0.14.0`、`certifi==2026.7.22`；Linux wheel 对照 PyPI 发布的 SHA-256 验证。与完整浏览器相比，这条已经验证的读取方式无需常驻浏览器进程和额外页面运行时。
