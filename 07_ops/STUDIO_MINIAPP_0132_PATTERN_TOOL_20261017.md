# 小程序 0.1.32：免费拼豆图纸工具（2026-10-17）

## 来源与范围

店主要求“我们把拼豆小店和图纸生成搬到小程序吧”，确认普通生成“完全免费就行”“可以 一起免费”，并回复“去做”。本版只加入普通（颜色量化）图纸生成；AI、积分、CDK、购买均不进入小程序（个人主体，0.1.23 曾因深度合成被拒）。小店作品展示（带价格、不可下单）留给 0.1.33。

## 功能

- 首页快捷按钮新增“拼豆图纸”，进入 `pages/tools/pattern`：选择或拍摄照片 → 选格数 26/52/78/104（默认 52）→ 生成 → 带色号图纸（可放大）、颜色清单、保存到相册、再做一张、到店预约。
- 请求 `https://pindoupuppy.com/api/v1/generate/script`（JSON base64，压缩至 1280 宽）。已登录用共享账号 token（作品进网站“我的作品”）；未登录用 `/wallet/profile` 签发的设备身份（`X-PinDou-Device`）。需要敏感信息同意时补记一次后重试；账号 token 过期改用设备身份；设备身份被拒换新一次。
- 保存图纸用普通 HTTPS 请求取 PNG 再写相册，只依赖已配置的 request 合法域名。
- 发布闸门 `check-studio-package.cjs` 放行 `pages/tools/pattern`，并新增拒绝 `/generate/ai`、`/generate/status`、`/payment/`、`/cdk/redeem`、“AI 生成”“AI 积分”。

## 验证
