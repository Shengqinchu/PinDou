# 顾客身份资料与预约核对 · 2026-09-12

授权：店主要求微信顾客的信息在后台可以对应预约，并明确“可以，去做吧，做完去提交”。

## 实现

- 小程序微信登录后检查资料，提示填写昵称、预约称呼和联系方式，可稍后填写。头像使用原生 `chooseAvatar`，昵称使用 `input type="nickname"`；微信号由顾客选填，不宣称登录自动读取。
- 网站资料编辑与小程序共用同一账号，保存头像和昵称后刷新 Studio 的资料缓存。小程序昵称改走 `PUT /studio-api/auth/profile`，由服务器调用现有共享账号的 PATCH 接口；修复微信原生请求不支持 PATCH 的问题。
- 新增每个账号固定的 `PD-…` 顾客编号。后台顾客列表、顾客详情和预约详情展示头像、昵称、预约称呼、编号和已提供的联系方式；支持按编号、姓名、电话、邮箱及微信号查找。
- 联系方式只用于展示、联系和搜索；账号、预约及资产继续按已验证的稳定用户 ID 隔离，同名或相同联系方式不会合并账号。旧版客户端未提交选填微信号时不会擦除新字段。
- 旧默认名增加区分后缀；自定义昵称与已有预约快照保留。已保存头像按原账号 ID 回填，不根据联系方式猜测账号。
