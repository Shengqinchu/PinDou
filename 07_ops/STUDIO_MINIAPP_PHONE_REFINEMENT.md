# 小程序手机布局与资料编辑 · 0.1.5

本轮依据店主 7 张 iPhone 截图实施。预约第一步和账号概览在常见手机上一屏展示，较矮屏幕允许内容区滚动；下一步、保存等主操作独立停留在窗口底部，并避开底部安全区。

## 改动

- 小程序详情页撤下大标题及“预约到访，可比约定时间稍早一点到”“抵达时店主会去楼下迎接”；保留地址、联系方式、停车及工具信息。底部“来拼豆吧”增加日历图标。
- 小程序预约页撤下“储值优惠·到店了解”标题，保留实际优惠价格与规则。小时／全天卡片合并标题、图标和选中状态，减少价格与说明之间的空白。
- 预约结果撤下可见的 VIS 编号和时钟大图标；编号仍用于 API 路由与预约识别。信息改为紧凑的标签／值布局。
- 账号首页展示头像、昵称、余额、预约资料摘要；“编辑资料”进入独立表单，可修改头像、昵称、预约称呼和联系方式。原生 `chooseAvatar` 只选择和预览图片，点击保存后才上传；昵称输入使用 `type="nickname"`。
- 取消弹窗保留预约日期、保留预约和确认取消，撤下长规则、次数及重置日期。服务端每个 Toronto 自然月最多自行取消 3 次的校验继续执行，超过上限时仍提示联系店主。

此次文案撤下仅针对截图中的小程序页面，网站已有文案未一并删除。中文／英文内容合同共 69 个模块，来源 `owner-miniapp-phone-profile-20260910`。中文手写字体补入“编辑资料”字形，继续使用店主原品牌图片。

## 共享资料

昵称和头像复用现有网站接口：`PATCH /api/v1/user/profile`、`POST /api/v1/user/avatar`（multipart 字段 `image`），沿用同一账号、Bearer 令牌和服务端图片校验。生产 OpenAPI 只读核验确认两个接口存在，未部署生成器中其他正在开发的代码。

预约称呼与联系方式使用既有 `/studio-api/auth/booking-profile` GET／PUT 接口及版本号。保存冲突允许读取最新预约资料；分步保存部分成功后保留未完成内容，重试不重复提交已经保存的字段。每步核对账号与令牌，防止切换账号后继续应用旧响应。

尚未设置昵称的账号通过稳定用户 ID 的 SHA-256 前 8 位生成固定默认显示名，如 `拼豆用户_AB12CD34`。没有批量写回用户昵称；客户自己设置的名字原样保留。管理员账号摘要在账号访问时通过既有成员同步逻辑更新，预约历史中的称呼不重写。

布局采用账户概览、按需进入编辑、显式保存的方式，参考 [Shopify 客户账户编辑流程](https://help.shopify.com/en/manual/customers/customer-accounts)。原生交互依据 [DCloud button](https://uniapp.dcloud.net.cn/component/button.html)、[input](https://uniapp.dcloud.net.cn/component/input.html) 和 [uploadFile](https://uniapp.dcloud.net.cn/api/request/network-file.html) 文档。

## 验证

- Studio 后端全套 **301 项通过**；新增默认昵称稳定性、不同账号区分、自定义昵称保留测试。
- Studio 网站、原生小程序、同组件 H5 构建通过。
- 编译后的 H5 在 Chromium／WebKit 共 **112 个中英文页面状态**通过：320×568、375×667、393×852、430×932、768×1024、1024×768、844×390；检查水平溢出、按钮／底栏可见、常见手机首屏及表单保存，模拟底部安全区 34px。
- 微信开发者工具 Stable 2.01.2510290、基础库 3.17.2 实际运行：昵称与预约资料保存、原生头像选择处理、上传失败保留并重试、取消普通及达上限状态通过。原生 WXML 绑定处理函数驱动，网络使用隔离 fixture；没有修改真实顾客资料或发送通知。
- 原生 390px 宽、内容窗口 753px 实测：编辑资料内容高度 467px，滚动区域 593px，保存操作栏底部 753px；账号与预约第一步内容也能放入各自可见区域。取消弹窗在可见窗口内。
- 原生软键盘事件不支持被官方自动化 SDK 模拟，真机键盘、头像选择器及外观仍以店主验收为准。H5 留图用于视觉预览，未冒充原生手机截图。

证据位于忽略目录 `artifacts/miniapp-phone/`：`web-checks.json`、`native-checks.json`、`live-profile-capabilities.json`、各页面预览图片及发布记录。模拟头像使用现有公开品牌 PNG；测试后已恢复开发工具中的账号存储和请求方法。
