用户来源：2026-09-09 的四项要求，见 `02_product/copy/STUDIO_COPY_CHANGES.md` 对应授权记录。

## 实现

- 首页顶栏与移动菜单加入生成器 `/upload`，使用整页同源导航；生成器首页链接回主站。
- 主站和生成器继续使用同一个生成器用户 ID、邮箱账户与 `pd_web_token`，跨标签页监听登录、退出；已打开的工具也同步。生成器的 `/login` 统一转入 `/account`，安全返回原工具路径。
- `/account` 共用原有邮箱验证／密码登录组件、时长钱包和积分查询；生成器账号菜单可直接进入。原工具的 AI 点数没有换算成工作室积分。
- 语言入口显示目标语言自身名称 English／中文；首次访问根据浏览器第一首选语言，手动选择优先并保存。
- `authing_login.py` 处理授权码、PKCE S256、state、nonce、受限回调与返回地址；验证 HS256 或固定 JWKS 的 RS256 签名及 issuer/audience/有效期。第三方令牌不进入前端。首次微信登录须确认已验证邮箱，后续微信登录返回原账户。
- 生成器新增仅限 loopback 的 HMAC 身份交换，30 秒断言与单次 nonce；只能签发已有邮箱用户的普通用户令牌。公开 Nginx 路径返回404，不创建管理员／搬移资产。
- 微信回调不写入 Nginx access log；会话页面 no-store/no-referrer。密钥只在被忽略的本地及服务器环境文件中，文档、前端与 Git 不含值。
