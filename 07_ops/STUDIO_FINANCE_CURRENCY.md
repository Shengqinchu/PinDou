# 营业收支：RMB 与 CAD

来源：2026-09-11 店主截图 a39230fc、c5692c41、481ae4fa，要求收入/支出分币种录入，汇总转CAD，收款方式固定为现金、EMT、微信/支付宝、储值抵扣。此记录覆盖此前仅按CAD录入的约定，实际收款统计口径保持。

- 收入选择微信/支付宝自动用RMB（数据库标准代码CNY），现金/EMT/储值抵扣按CAD；支出可直接选择CAD或RMB。网页、小程序使用同一组方式键，兼容旧现金/电子转账显示值，保留旧记录的其他方式。
- `amount_cents`保留原币整数分；新增币种、参考汇率、汇率日期、来源及CAD整数分。原CAD记录迁移为1:1，不改金额、日期、版本或既有修改历史。没有金额的完成预约草稿继续待补，不估算收款。
- 加拿大央行Valet `FXCNYCAD`公开接口，无密钥/接口费用。按收支日期取当日或此前14天内最近可用日；日内尚未发布时可用最近工作日。缓存查询；每条记录保存其所用汇率和日期。只改原币金额/备注等时保持汇率，修改收支日期则取对应日期。没有可用汇率时保留输入并阻止错误落账。
- 服务端Decimal按分四舍五入，合计与分类收入均使用CAD金额。人民币列表同时显示原额及折合CAD。旧客户端编辑RMB记录时被要求更新，避免把人民币误当加元。
- 11项后端检查覆盖金额精度、双币种汇总、方式识别、历史汇率冻结、重试、旧CAD迁移、鉴权、来源异常与工作日选择。网页四种尺寸、小程序H5三种尺寸通过新增RMB记录、方式与币种同步、汇率失败保留输入、CAD合计及无横向溢出。所有写入验证使用回环QA和虚构记录。

来源：[加拿大央行API说明](https://www.bankofcanada.ca/valet-api-how-to/)；[每日参考汇率](https://www.bankofcanada.ca/rates/exchange/daily-exchange-rates/)。接口实读确认2026-09-11为1 CNY = 0.2067 CAD；实际记录按其日期获取，不硬编码该值。
