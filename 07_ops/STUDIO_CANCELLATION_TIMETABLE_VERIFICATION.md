# 顾客取消预约与后台连续色块

来源：2026-09-10 店主要求在预约详情和“我的预约”各增加取消入口，每账号每月最多取消三次，操作前弹窗说明；后台一组客人一个色块，名称、备注、人数只显示一次，重叠预约分列。

## 实现

- 详情页刷新操作旁和账号预约列表均可取消。共用原生 dialog、项目弹层动画和滚动锁；显示每月规则、已用次数、本次操作后剩余次数、下一次重置日期，并提供“保留预约”。达到上限后改为说明及联系店主。
- 账号按稳定登录 ID 隔离；以取消发生时的 America/Toronto 自然月计算，最多 3 次。店主后台取消不计入顾客额度，不回溯计算旧有管理员操作。
- 只允许本人自行取消尚未开始的 pending/confirmed 预约；已删除、已完成或已有实际到店时长的记录需店主处理。没有增加提前 2 小时的取消限制。
- 同一数据库事务内检查版本/次数、更新状态、追加取消计数和事件。并发不能超额；已提交但响应丢失时可按原版本重试，不再计数。管理员重新激活后再次取消按新的成功操作计数，删除预约不清除历史次数。
- 取消后已确认时段释放；无自动退款、扣时或积分改动。“我的预约”使用预约状态词，修复误显示付款订单“等待付款”的问题。
- 后台时间表保留半小时坐标，新增每组完整预约记录。一块覆盖起止时间，称呼、备注、人数显示一次，重叠组采用不同列。备注来自店主顾客备注、预约私密备注及本次预约备注，去重合并；只在管理员接口返回，顾客接口不返回私密内容。
- 色块可打开准确的预约详情，包括当前列表分页之外的记录；空白格仍可筛选时段。名称为空时使用账号名称或预约编号，不凭姓名合并账号。
- 按容器宽度显示 1/2/3/4/7 天。长备注在色块摘要中折行并限行，悬停可看全文，点击可进详情；文字位于色块上方并随内部滚动保持可见。
- 新增 reservation-cancellation 双语模块，只更新与新功能相关的说明；66 个内容模块通过文案检查。服务端默认内容同步，既有店主发布覆盖保留。中文字体子集已重建。
