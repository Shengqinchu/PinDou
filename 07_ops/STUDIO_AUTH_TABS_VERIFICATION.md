# 2026-09-09 / 注册、登录、微信登录

来源：店主要求登录弹层默认账号密码，顶部依次为注册、登录、微信登录，并改善手机授权的品牌识别。此前明确邮箱验证码只用于找回账号。

## 本次实现

- 弹层、账号页、预约登录与生成器共用 AccountPanel。默认密码登录；关闭后再打开恢复登录标签。微信二维码仅在点击微信标签后创建，离开标签或关闭时停止轮询。原页面、预约草稿和登录后的共享身份保留。
- 注册使用邮箱、密码、确认密码，无验证码或自动发信。独立的 password-register 接口经签名、短时、一次性断言转发到生成器账号服务。密码散列、账号插入和原有生成器注册礼在同一事务完成；已存在邮箱或稳定 ID 均拒绝创建，不能覆盖旧密码或领取旧资产。未验证的邮箱不能抢注拥有无限额度的保留地址。
- Studio 166 注册积分沿用稳定账号 ID 的幂等明细；重复响应、重新登录不会重复发放。账号切换按账号 ID 重建身份与钱包组件，避免新账号标题下短暂显示上个账号的余额。
- Authing 应用显示名已改为“小狗拼豆铺 · PinDou Puppy”，应用图标和微信扫码连接图标均使用原版 puppy-icon-256-v6.png。应用 ID、身份源 ID、登录权限、绑定映射和回调未变。
- Authing WXAPP_AUTH 返回的 customLogo 按官方 JS SDK 的中心直径 1/2.4 合成到完整图片；保留外围码点，加载失败退回原二维码。实测 autoMergeQrCode=true 未带上自定义图标，所以未采用该参数作为品牌显示保证。

## 验证

- 账号相关 Studio 57 项、针对固定生产源的生成器账号 13 项测试通过，包含重复邮箱、历史无密码账户、稳定 ID 冲突、并发注册、保留地址、限流、签名、角色、找回验证码单次使用与独立用途。
- 44 个中英文/窄屏/桌面/WebKit 账号界面状态通过；键盘标签导航和可见表单 axe 检查通过。
- 独立临时数据库与实际 HTTP 账号桥接完成注册、生成器 JWT 读取身份、退出、重复注册拒绝、原密码重新登录、166 积分单次奖励及预约草稿保留；没有发邮件。
- 独立账号切换测试：延迟新钱包返回期间，旧余额出现在新账号标题下的帧数为 0。
- 真实 Authing 图片合成检查：430×430，中心以外变化像素为 0，小狗黑色像素 2962，中心蓝色 Authing 像素 0；图标不可用时回退原图。此结果不等于手机实际扫码已验收。
- 之前的二维码状态、过期重试、绑定已有账号、找回密码、弹层关闭、减少动态效果、双人套餐刷新不闪烁回归通过。
