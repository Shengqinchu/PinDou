# 小店框架与目录上线验收

对应 [小店任务](../02_product/STUDIO_SHOP_20260912.md) 与用户《小店.pdf》。本轮网站上线，未更改自有微信小程序包或其审核状态；登录并读取的是用户提供的拼团呀来源小程序。

## 功能

- `/shop`：在家拼豆 / 拼豆成品 / 代拼代烫，25个分类节点；两级分类、色号搜索、原图与多图详情，桌面和手机自适应。
- `/manage?view=shop`：新增小店商品入口；商品名称、介绍、分类、色号、价格、库存、展示状态、图库及封面可编辑；分类/系列可新增和编辑。
- 两个服务条目已建好，成品等店主录入；源目录230项补充装与19张原图已导入。211项源条目无图，显示待补图并支持之后上传。
- 用户确认统一 CAD 价格由其提供，当前230项均无售价、库存0、active=false、可展示。来源人民币价仅管理员可见；不冒充本店价格或库存。
- 使用现有购物车存储和订单访问凭据；订单列表说明为此浏览器保存的记录。在线新下单仍由已有服务端总开关阻止。
- 栏目/分类切换只筛选缓存数据，不重复拉取整个目录；各栏目独立保留搜索词。后台页面KeepAlive保留筛选及草稿，多图上传复用原有受限媒体接口。

## 核验

29项既有交易/工作台后端测试、5项新增目录测试通过。覆盖类别层级/循环校验、隐藏父分类连带隐藏商品、版本冲突、图片路径限制、多图去重、重复导入不覆盖店主改价、供应商资料不公开、交易暂停及管理员权限。

Chromium与WebKit两组浏览器流程通过：分类/搜索、跨栏目保留、仅一次目录请求、购物车增删及重载后保留、订单入口、两项服务、商品改价、原图多图上传/封面切换、新增子分类、手机编辑窗口。检查320/390/844/1440/2560宽度，无页面横向溢出。独立本地临时数据库，未向真实顾客发送测试消息或创建真实订单。另人工视觉核对窗口动画完成后的390px布局。

`check:copy`、TypeScript、Vite构建通过。原首页组件和首页文案没有修改。
