# ADR-006: 小程序主体 — 个人

- **状态**: Accepted
- **日期**: 2026-05-24
- **决策者**: 用户 + Claude Code
- **影响范围**: 小程序注册、AIGC 备案、税务、责任主体

## 背景
微信小程序注册主体分"个人 / 个体工商户 / 企业 / 政府 / 媒体 / 其他组织"。不同主体的差异：
- 个人主体：注册门槛低（身份证 + 微信），但**类目受限**（不能做支付、不能做 AIGC 工具类、不能挂广告联盟）
- 企业 / 个体工商户：可开通几乎所有类目，但需要营业执照、对公账户、年费

## 决策
**MVP 阶段以"个人"主体注册小程序**。

## 理由
- 副业现金流目标 6,000-10,000 RMB/月，前期收入有限，企业主体的年成本（营业执照 + 对公账户 + 记账 + 年报）会吃掉大部分利润。
- 个人主体足够支撑前期内测 + 小红书冷启动验证。
- 等 PMF 跑通（月入达到下限目标）再升级主体。

## 后果

### 正面
- 注册快（个人主体即时通过 vs 企业主体审核周期）
- 成本几乎为零

### 负面（必须正视的限制）
1. **个人主体不支持微信支付**：付费功能（ADR-003 的 9.9 / 28 月卡）需要替代方案：
   - 选项 a：跳转外部 H5 支付 / 引导到小红书私聊收款（早期可接受）
   - 选项 b：升级主体后再开支付
2. **个人主体不能挂激励视频广告联盟**（流量主功能不开放给个人主体的部分类目）：
   - ADR-003 的"广告续次"变现路径可能要等主体升级
3. **AIGC 类目（生成式人工智能服务）个人主体审核难度更高**：
   - 部分 AIGC 类目要求企业主体 + 算法备案
   - 任务 F 合规调研必须明确"个人主体能上哪些类目"

### 2026-05-26 补充：虎皮椒支付码作为 Phase 2 过渡方案

支付链路阶段性方案确认：
- 不接入虎皮椒 H5 跳转：用户需要离开小程序，支付后再返回，转化断点明显。
- 接入虎皮椒支付码方案（ADR-011）：小程序内展示二维码，用户长按识别付款，后端 webhook 验签后自动开通权益。
- 保留"加客服扫码付"作为兜底入口，避免虎皮椒不可用时阻断转化。
- 长期触发条件不变：月入 ≥ 1500 RMB 或出现稳定付费需求后，升级个体工商户 + 官方微信支付。

### 风险
- 上述三条限制可能直接卡死部分变现路径。
- **触发升级主体的条件**（写入 FUTURE_WORK.md 后续会加）：
  - 类目审核被拒，且差异点明确指向主体类型
  - 或：月入达到目标下限的 50%（约 3000 RMB/月），考虑升级
  - 或：用户量 > 1000 且付费需求强烈

## 备选方案
- **个体工商户**：成本低于企业（无对公账户硬要求、可微信支付），但仍需办执照。**作为下一步升级首选**。
- **企业主体**：被否，MVP 期成本过高。
