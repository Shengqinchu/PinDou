# ADR-002: 色卡支持 — MARD + COCO 双色卡

- **状态**: Accepted
- **日期**: 2026-05-24
- **决策者**: 用户 + chat 端 Claude
- **影响范围**: 量化算法、材料清单、定价、采购引导

## 背景
拼豆爱好者主要使用 MARD（色全，300+ 色号）和 COCO（轻量，定位入门）两种品牌的色卡，单色卡覆盖会丢失一部分用户群体。同时，色卡间存在可替代色号，用户经常问"我手头是 COCO，能不能照这个 MARD 图纸做"。

## 决策
- **同时支持 MARD + COCO** 作为目标色域。
- **生成时支持单色卡限定**，输出图纸用对应品牌色号标注。
- **提供跨色卡可替代对照表**（基于 CIEDE2000 色差近邻）。
- **优先级（默认色卡 / UI 入口顺序）**：待 Phase 0 任务 D 调研产出数据后定（参考维度：色号完整度、市场覆盖率、电商可买性、价格）。

## 理由
- 双色卡覆盖绝大多数中文拼豆用户。
- 跨色卡对照是高频需求，可成为差异化卖点。
- 自有色卡（自建色域）门槛过高，Phase 1 不做。

## 后果
- 正面：用户群更广，跨色卡功能可营销。
- 负面：色卡数据维护成本翻倍（价格、库存、电商链接需追平）。
- 风险：MARD / COCO 是品牌名，商品描述中使用边界需要任务 F 合规调研确认。

## 备选方案
- **单 MARD 色卡**：被否，遗漏 COCO 用户群。
- **自有色卡**：被否，Phase 1 之前不做。
