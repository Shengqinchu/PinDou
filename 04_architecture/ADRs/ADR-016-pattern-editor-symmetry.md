# ADR-016 图纸编辑器（点格换色）+ 对称性

- 状态：已采纳（2026-06-02）
- 决策人：用户拍板（自测发现对称问题 + 要可编辑）；chat 端 Claude 设计

## 一、对称性
- 现象：本应对称的卡通脸，输出左右不对称（嘴多一颗 H7、脖子 4/2/2/3、耳朵不对称）。
- 根因：主体未对齐采样网格的对称轴 → 亚像素偏移在粗网格被放大 + 每格主色投票放大边缘微差。非纯 bug，是"没让采样对齐对称轴"。
- 决策：
  1. 生成前**主体居中对齐网格**——便宜、普惠，已做（Prompt B）。**但只修宏观错位，不能让本应对称的图真对称**（源图抗锯齿微差 + 每格投票仍产生局部不对称）。
  2. **镜像对称强制（实测后升级为必需）**：检测竖直对称轴，对称度高于阈值则把较干净一半镜像到另一半（或每对镜像格取一致码）。**真实照片不对称，强制会毁 → 必须 自动检测高对称才触发 + 用户"对称模式"开关**。这才是让嘴/耳/脖对称的真正手段。
  3. 残余不对称由编辑器人工修。

## 二、图纸编辑器（新功能）
目标：生成后用户可点格换豆色号；图纸做成矢量可放大、自由点击交互。

### 渲染
- 矢量/可缩放、任意放大清晰、每格可点击。≤52 用 SVG（天然矢量+可点）；104（10816 格）若 SVG 卡，用 canvas + 手动缩放/命中检测，保证缩放清晰。
- 网格线、色号、放大后仍清晰。

### 数据/保存
- 可编辑网格状态（行×列 色号）；编辑后重算色号清单/豆数。
- 后端加保存接口：持久化编辑后的 pattern_json + 重新导出图纸 PNG，挂到该 artwork。
- Undo/Redo。

### 桌面交互
- 点格子 → 弹出色卡（MARD 色板）→ 选色 → 该格更新。
- 滚轮/按钮缩放，拖拽平移。

### 手机交互（参考颂拼豆 / 像素画编辑器，解决触控不精细）
- 底部**色卡托盘**选"当前色"。
- **双指捏合缩放 + 双指平移**；放大后格子够大才好点。
- **编辑模式下单指点/拖 = 用当前色上色**（点一格/拖一片）。
- **放大镜 loupe 或高亮目标格 + 显示该格当前色号**（解决手指遮挡、看不清点中哪格）。
- **模式切换：浏览(缩放/平移) ↔ 编辑(上色)**，避免手势冲突。
- Undo 按钮常驻。

### 批次建议（旧）
- Batch 1：矢量可缩放网格 + 桌面点格换色 + 保存 + Undo。
- Batch 2：手机端 上色模式 + 捏合缩放 + loupe + 模式切换。

## 编辑器重做（2026-06 实测后定稿：SVG→canvas + 独立全屏 /editor）
实测发现现 PatternEditor.vue 用 **SVG 渲染**（每格 `<rect>`+色号 `<text>`，52×52≈8000+ 节点，104 放大可达 3 万级）→ 手机拖拽卡顿、不跟手、无双指缩放、难精准点格。Codex 评估 Go，chat 端 Claude 审查接受 + 补充。
- **决策**：DOM/SVG → **2D canvas 渲染**；新增**独立全屏 `/editor/:id`**（结果页只作入口）；手机端 **间接游标 + loupe + 底部色盘**（参考 Pixilart/dotpict/Picotap，解决手指遮挡）。
- **canvas 要点**：grid-space 坐标 + scale/offset 视图变换；视口裁剪只画可见格；rAF 合并 pointermove；HiDPI(devicePixelRatio)；格太小不画色号；O(1) 命中检测；loupe 用第二 canvas 从 grid state 重画（非截图放大）。
- **Claude 补充 4 点（焊进实现）**：
  1. **iOS Safari 头号风险**：双指被抢当页面缩放、pointercancel、地址栏收缩改 viewport、橡皮筋滚动。`touch-action:none`+`overscroll-behavior:none`+视口 meta；**Batch 2 末必须真 iOS Safari 验手势**，别拖到最后。
  2. **分层 canvas**：静态图纸层(offscreen，缩放/平移才重画) + 游标/loupe overlay 层(每帧只重画此层)。游标移动不重绘全网格——手机"跟手"的核心。
  3. **补"拖动连续涂"模式**：精准用游标+确认；放大到单格够大时允许一指拖动连续上色（否则改大色块要点几十次）。
  4. **PM：Batch 1-4 能用即可上线，Batch 5 打磨别挡冷启动**；多数用户不编辑，核心闭环(生成→保存→作品集)优先。
- **手势仲裁**：一指=移游标(不直接落色)；双指=pinch缩放+平移(双指期间禁单指落色)；桌面=鼠标直接点格+滚轮缩放。
- **数据/保存**：只改 pattern.grid[row][col]，复用 recalculatePattern 重建清单/豆数；Undo 用 patch 栈 {row,col,before,after}；保存走 saveArtworkPattern，成功后 swrCache.setArtwork + invalidateGallery；**后台 SWR 刷新不得覆盖未保存的本地编辑(本地态优先)**。
- **批次**：1 全屏壳+canvas只读渲染 → 2 缩放/平移/命中(+iOS真机验) → 3 游标+loupe+底部色盘 → 4 编辑态/undo/保存/自动保存 → 5(可选)迷你预览/快捷键/脏数据离开确认。

### Addendum：撤销 loupe（2026-06-05）

用户明确不要图纸编辑器里的 loupe 放大镜。当前交互已通过缩放、直接点格上色、HUD readout（实时显示当前格行列与色号）覆盖手指遮挡问题，因此撤销 loupe；遮挡顾虑由 HUD 实时显示当前格行列 + 色号承接，画布上仍保留 cursor 光标圈。

### Addendum：开始上色开关（2026-06-05）

手机端旧约束“一指=移游标不直接落色”调整为由“开始上色”开关仲裁：关闭时一指只定位/浏览，开启时一指点格或拖动按当前工具（画笔/橡皮擦）落色；双指缩放/平移期间和结束后的短暂 settle 窗口仍禁止落色。桌面端开启“开始上色”后允许左键拖动连续上色，关闭时左键点格上色、拖动平移保持不变。
