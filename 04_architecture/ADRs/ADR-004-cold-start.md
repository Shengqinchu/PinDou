# ADR-004: 冷启动渠道 — 小红书账号矩阵

- **状态**: Accepted
- **日期**: 2026-05-24
- **决策者**: 用户 + chat 端 Claude
- **影响范围**: 增长、内容生产、客服、产品功能优先级

## 背景
拼豆社区高度集中在小红书。买量 ROI 低、抖音不匹配（视觉静态向）。用户女朋友 OCADU Digital Future 背景，视觉训练有优势。

## 决策
- **冷启动唯一主渠道：小红书账号矩阵**。
- **运营负责人：用户女朋友**。
- **前期手动接单**：用工具辅助生成，人工兜底质量，沉淀真实订单数据反哺算法和定价。
- **内容定位**：人像 / 宠物 / 情侣三个场景纵向打透，避免泛拼豆赛道竞争。

## 理由
- 拼豆用户密度小红书最高。
- 女朋友视觉能力可直接生产高质量内容，省外包成本。
- 手动接单阶段沉淀的素材是 AI 微调 / Prompt 调优的关键语料。

## 后果
- 正面：冷启动成本可控、内容护城河可累积。
- 负面：早期高度依赖单一渠道，平台规则变化即风险（限流、违禁词、广告引流封号）。
- 风险：小红书对"明显引流到小程序"打压较严，需研究合规话术（任务 E 输出 playbook）。

## 备选方案
- **抖音 / 视频号**：被否，视觉静态品类不适配。
- **微信社群裂变**：备选，等账号矩阵有粉丝池后再启动。
- **付费投流**：暂不做，等内容跑出转化数据再考虑。
