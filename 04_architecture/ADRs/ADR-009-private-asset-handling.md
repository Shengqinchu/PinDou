# ADR-009: 私人素材处置规则 — 不入 Git + 摘要规则

- **状态**: Accepted
- **日期**: 2026-05-24
- **决策者**: 用户 + Claude Code（基于 Codex Task C 实操经验 + ADR-007 风险接受 + ADR-006 个人主体限制）
- **影响范围**: 全 Phase 所有真人 / 第三方版权素材处置；Codex / Gemini 工作流；Phase 3 提审

## 背景
Codex Task C 私有素材实验涉及：
- 真人照片（用户女朋友 / 朋友 / 自拍）
- 宠物照（可识别归属）
- 第三方版权材料（社媒头像、IP 形象）

如果这些素材进 git：
- 跨境合规风险加剧（ADR-007 已接受反代风险，但素材入 git = 永久存档全网公开）
- 第三方肖像权 / 版权风险（公开仓库即使私有也可能泄露）
- Phase 3 微信审核可能查仓库残留

## 决策

### 不入 Git 的素材类别（hard rule）
1. **任何真人照片**（含用户自己、家人、朋友、客户）
2. **任何可识别第三方主体的宠物 / 物品照**
3. **任何第三方版权材料**（电影截图、动漫角色、品牌 IP、明星照）
4. **任何用户提供的原始素材**（即使来源说不清也按私人处理）
5. **基于上述素材的 AI 生成图 / 量化输出图 / 中间产物**

### 入 Git 的内容（白名单）
1. **合成测试图**（AI 生成假人脸、AI 生成抽象图、CC0 公开素材）
2. **摘要文档**：实验观察、结论、prompt 优化、问题清单（不附原图）
3. **统计数据**：成功率、延迟、成本、色数等数值
4. **图片元数据**（不含原图，只含 hash / 尺寸 / 颜色直方图等不可还原信息）

### 摘要文档规范
私人素材实验完成后必须产出一份摘要，存到 `01_research/tech/private_run_summaries/<run_id>.md`，包含：
- run_id（日期 + 主题）
- 素材类型（"真人情侣合影" / "宠物猫" 等抽象描述，不含识别信息）
- 数量
- 用了哪些 prompt
- 关键观察（哪条 prompt 有效 / 哪条失败）
- 结论 / 决策影响
- **不附原图 / 不附 AI 生成图**

### 私人素材物理位置
- 本地路径：`01_research/tech/user_poc_private/`
- 子目录按 run_id 组织
- **必须**在 `.gitignore` 中显式排除（防 `.git/info/exclude` 丢失）
- **必须**在 `.gitignore` 中显式排除 `01_research/tech/user_poc_private/incoming/`（用户素材投放点）

### 删除规则
- 实验完成 + 摘要写完 → 原始素材**30 天内本地删除**
- 中间产物（AI 生成图等）实验完成立刻删
- 用户作品集场景在 Phase 2/3 后端实现时，遵循同样规则（不存原图 / 短期保存 / 自动删除）

### Codex / Gemini 必须遵守
- 看到 `user_poc_private/` 下任何素材，禁止 commit
- 任何 commit 前 check 是否包含真人 / 第三方版权材料
- 不确定就在 `_questions_for_user.md` 问，不要自己拍板
- 真实素材运行结果只产出摘要文档进 git

## 理由
- 跨境合规（用户上传到日本机的素材若进 git → 公开传输 + 永久存档，远超 ADR-007 接受的风险范围）
- 第三方版权 / 肖像权（无授权使用 = 民事 + 刑事风险）
- 微信小程序提审 / 监管查处时，git 仓库公开内容是关键证据
- 即使私有仓库，账号被攻击 / 离职 / 误公开都可能泄露

## 后果

### 正面
- 合规基线（最低限度的隐私防护）
- 摘要文档化反而强迫提炼洞察（不能靠"看图说话"水报告）
- Phase 2/3 用户素材处置规则有原型可参考

### 负面
- 实验复现性变差（其他人 / 未来 Claude 看不到原图）
- 摘要质量取决于写的人

### 风险
- 摘要不严谨 → 后续决策依据有偏（缓解：摘要必须含数据 + 实验配置，不只是"结论"）

## 备选方案
- **全入 git 私有仓库**：被否，私有仓库也会泄露，且违反 ADR-007 精神
- **完全口头沟通，不留任何文档**：被否，复现性差、决策无据
- **加密入 git**：被否，引入额外工具链 + key 管理负担

## 配套操作（本 ADR 通过后立刻执行）
1. `.gitignore` 加：
   ```
   01_research/tech/user_poc_private/
   01_research/tech/user_poc_private/incoming/
   ```
2. 检查现有 git 历史是否有私人素材残留（如有 → 单独决策处理）
3. 在 `00_meta/codex_briefs/README.md` 通用规则追加引用本 ADR
4. Phase 1 PRD 设计用户作品集时复用本 ADR 思路
