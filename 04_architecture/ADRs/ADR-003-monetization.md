# ADR-003: 变现结构 — 脚本免费+广告 / AI 付费 / CDK 兑换 / 人工精修

- **状态**: Accepted（2026-05-24 修订）
- **日期**: 2026-05-24（首版）/ 2026-05-24（修订）
- **决策者**: 用户 + Claude Code
- **影响范围**: 产品形态、定价、广告 SDK 接入、客服流程、引流策略
- **修订记录**: 取代首版"3 次免费基础生成 + 广告续次 + AI 付费购买"的统一变现路径；现在改成双管线分层

## 背景
首版决策的"基础生成 vs AI 高级风格化"边界模糊，且默认所有用户都进 AI 路径，免费 3 次用完才付费。用户在 PRD v0.1 review 时提出更优分层：
- **脚本生成（K-means 量化）**：质量一般但成本几乎为零 → 适合作免费 + 广告续次的承接面
- **AI 生成（Q 版 + FinishedPreview）**：质量明显更好但有 API 成本 + 反代风险 → 适合作付费高客单
- **CDK 兑换**：用户在小红书 / 闲鱼销售 CDK 字符串，作为引流和裂变工具

差异化产生付费动机：用户先用脚本路径看到"够用但不够好看"的图纸 → 自然想要 AI 版本 → 转化。

## 决策

### 双管线 + 四层变现

| 层 | 入口 | 谁付费 | 价格 | 实现 |
|----|------|--------|------|------|
| **脚本生成（免费 / 广告）** | 默认入口 | 不付费用户 | 0 元 | 每天 N 次免费 + 看激励视频续次 |
| **AI 生成（体验 + 付费）** | 隐藏在"AI 精品"按钮 | 想要好质量用户 | 体验 1 次 + 单次 9.9 / 月卡 28 | 加客服扫码付（ADR-006 个人主体限制） |
| **CDK 兑换** | 小红书 / 闲鱼引流 | KOL / 团购用户 | 用户在外部购买 CDK 后兑换 | 后端 CDK 表 + 兑换接口 |
| **人工精修** | 客服私信 | 高难度需求用户 | 99 元起 | 加客服微信外部接单 |

### 免费 + 广告具体规则
- 脚本生成：每日免费 3 次（按用户维度）
- 用完后看激励视频 → 续 1 次（每日上限 10 次）
- 激励视频流量主开通条件：UV ≥ 1000 + 类目通过审核（小程序工具类）
- 在 UV < 1000 期间：免费 3 次用完后只能等次日重置 / 转 AI 付费

### AI 体验机制
- 每用户**首次进入"AI 精品"** → 免费体验 1 次（生命周期 1 次，不每日重置）
- 体验后继续用 → 必须付费（9.9 / 月卡 / CDK）
- 体验目的：让用户感受 AI vs 脚本的视觉差异，建立付费动机

### CDK 业务规则
- CDK 形态：18 位字符串（字母数字混合），人类可读
- CDK 类型：
  - `single_use`：兑换 1 次 AI 生成
  - `monthly_card`：兑换 1 个月月卡
  - `credit_pack_N`：兑换 N 次 AI 生成
- CDK 生成：后台手工 / 批量生成接口，由你或女朋友操作
- CDK 销售：闲鱼挂"PinDou AI 月卡 CDK 28 元"等商品；小红书博主合作做抽奖 / 团购
- CDK 状态：`active / redeemed / expired / void`
- 防滥用：每个 CDK 一次性使用，绑定首次兑换用户

### 定价（与首版一致 + CDK 通过相同价格锚定）
- AI 单次：9.9 元
- 月卡：28 元 / 月（不限 AI 生成 + 高级 PatternSheet 导出权限）
- 人工精修：99 元起
- CDK 闲鱼 / 小红书定价：用户自定，建议略低于官方（让买 CDK 显得"划算"+ 引流效果）

## 理由
- **脚本免费 + AI 付费**：让用户**感知差异 → 付费动机自然**（首版方案"统一免费 3 次"用户感受不到付费价值差）
- **脚本路径用广告变现**：长尾低付费意愿用户不流失，且广告 CPM 在拼豆这种女性向小程序有合理回报
- **AI 体验 1 次**：是付费转化的核心钩子，必须有但只 1 次（避免免费白嫖）
- **CDK 是低成本引流**：闲鱼自然搜索流量 + 小红书博主合作的低门槛尝试入口，比直接做付费投流 ROI 高
- **人工精修保留**：99 起的高客单兜底，配合女朋友女红绣视觉能力 + 沉淀真实素材

## 后果

### 正面
- 变现路径清晰，每条都有明确用户群
- 脚本路径 + 广告承接低意愿用户（不流失）
- AI 路径差异化卖点突出（视觉对比明显）
- CDK 给了"非小程序内"的引流通道（闲鱼 / 小红书）

### 负面
- 双管线 = 后端要实现两套生成逻辑（脚本不调 PreviewProvider，直接走 PatternBuilder）
- 客服工作量增加（加客服扫码付 + CDK 后台操作 + 人工精修对接）
- CDK 防滥用 / 防伪造需要后端做安全设计

### 风险
- **AI vs 脚本视觉差异不显著**会让付费转化崩——已在 PRD v0.2 §4 强调，开发期视觉对比要做明显
- **CDK 灰产风险**：可能被黄牛 / 工作室批量倒卖；需要后台监控异常兑换
- **广告 SDK 接入依赖类目审核**：个人主体 + 工具类目可能流量主开通受限，需 Phase 3 前确认

## 备选方案
- **统一免费 3 次 + 付费续次**（首版）：被否，付费动机不清晰
- **脚本付费 + AI 免费**：被否，反代成本你倒贴，不可持续
- **纯订阅**：被否，工具场景留存差
- **不做 CDK**：被否，闲鱼 / 小红书的自然引流通道很有价值，CDK 是最低成本的入口
