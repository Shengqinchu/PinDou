# ADR-003: 变现结构 — 免费 + 广告续次 + AI 付费 + 人工精修

- **状态**: Accepted
- **日期**: 2026-05-24
- **决策者**: 用户 + chat 端 Claude
- **影响范围**: 产品形态、定价、广告 SDK 接入、客服流程

## 背景
副业现金流目标 6,000–10,000 RMB/月。拼豆图纸是低客单 + 高用量的工具型场景，单纯订阅难跑通；纯免费 + 广告又难达到目标。

## 决策
**四层变现叠加**：
1. **免费层**：3 次免费基础生成。
2. **广告续次**：看激励视频可续生成次数。
3. **AI 高级风格化**：付费单独购买（按次 / 月卡）。
4. **人工精修**：高客单服务，小红书引流，人工接单。

**定价初版**（待小红书冷启动测试后调整）：
- 基础包：9.9 元 / 次
- 月卡：28 元 / 月（不限基础生成 + N 次 AI 风格化）
- 人工精修：99 元起

**产品硬性要求**：必须把"普通量化"与"AI 预处理"的视觉差异做明显（PoC 阶段的可视对照将作为定价合理性证据）。

## 理由
- 三次免费降进入门槛、配合小红书内容引流。
- 广告续次承接长尾低意愿用户，不流失但有收入。
- AI 付费切走高价值用户（情侣 / 宠物纪念场景，付费意愿高）。
- 人工精修兜底超高要求订单 + 沉淀真实素材反哺算法。

## 后果
- 正面：变现路径多元、客单价分层覆盖。
- 负面：四层结构对运营复杂度要求高；激励视频广告 SDK 接入需要小程序类目支持。
- 风险：若 AI 视觉差异不够明显，付费转化会崩；这是 PoC（任务 C）的核心验收点。

## 备选方案
- **纯订阅**：被否，工具场景订阅留存差。
- **纯按次付费**：被否，门槛高、漏斗窄。
- **纯广告**：被否，难达月入目标。
