## 1. 写实人像作为 Phase 2+ 可选功能（ADR-005a 修订后降级）
- **当前决策**：Phase 1 主路线确定为 Q 版 FinishedPreview，写实人像降为 Phase 2+ 可选功能（"忠于原貌"模式）。GPU 决策路径在 ADR-005a 修订中关闭。
- **触发条件 = 重新评估**：
  - Phase 2+ 用户反复要求"做得像本人"成为 top 1 需求
  - 或：竞品上线类似"写实拼豆"功能且转化率高
  - 或：长辈纪念照 / 婚纱拼豆等特殊场景出现批量订单
- **回头要做**：重新评估技术路径（届时国内 GPU / 云 ComfyUI / API 演进版本都会变化，不预判方案）
- **预计阶段**：Phase 2+ 数据驱动
- **风险等级**：低（Phase 1 主路线 Q 版 + FinishedPreview 不依赖此项）
- **记录日期**：2026-05-24（修订）

## 2. 用户上传图片的跨境合规
- **当前决策**：MVP 期使用日本腾讯云服务器（`43.167.226.239`），用户上传图片直接存服务器本地磁盘
- **风险**：用户人像照属于《个保法》第 28 条敏感个人信息，存日本服务器构成"个人信息跨境传输"，理论上需要走标准合同备案 / 认证
- **触发条件 = 必须回头处理**：
  - 小程序提审前（Phase 3）— 否则可能直接被拒
  - 或：用户量达 ~1000 后任何一次合规投诉
  - 或：日方 / 中方监管政策变化
- **回头要做**：
  - 单独安排时间做跨境合规专项调研（不能塞进 Phase 0 任务 F 里草草过）
  - 评估迁回国内服务器（腾讯云广州 / 阿里云杭州）的迁移成本
  - 评估"图片不落盘只内存处理"方案（生成完即删，不存储）
- **预计阶段**：Phase 2 末 / Phase 3 初
- **风险等级**：高（直接影响上线）
- **记录日期**：2026-05-24

## 3. 服务器硬盘扩容 / 对象存储迁移
- **当前决策**（2026-05-24 用户确认走 B 路径）：MVP 期图片存上海机本地磁盘（80G，22G 已用，54G 可用）+ Nginx 静态反代。硬盘不够再扩容 / 迁对象存储。
- **触发条件 = 必须回头处理**：
  - **硬盘占用 ≥ 70%（约 56G 已用）— 这是最先触发的硬指标**
  - 或：图片访问 P95 延迟 > 2 秒
  - 或：合规问题（见第 2 条）触发整体后端迁移
- **回头要做**：
  - 先评估云厂商扩容（最快，但要钱；上海机可能能扩到 200G+）
  - 扩容代价高 / 触及云厂商上限 → 迁到对象存储（七牛 / 阿里 OSS / 腾讯 COS）+ CDN + 防盗链
- **预估到达时间**：按 PRD §6.5 用户作品保存策略 + 商业目标月活：
  - 月活 5000 → ~10 个月触发
  - 月活 1 万 → ~5 个月触发
  - 月活 3 万 → < 2 个月触发（PMF 期最危险）
- **预计阶段**：Phase 4 PMF 期
- **风险等级**：中高（PMF 期可能要紧急处理，建议提前 1 个月预备）
- **Claude Code 监控职责**：deployment.md §7.3 系统指标中"磁盘 > 80%"告警 → 立刻顶上来提醒

## 4. AIGC 算法备案
- **当前决策**：Phase 0/1 用反代 gpt-image-2 跑 PoC，研发期免备案
- **触发条件 = 必须回头处理**：
  - 小程序提审前（Phase 3）— 类目"AIGC 工具"硬要求
  - 或：用户量达 ~1 万触发监管关注
- **回头要做**：
  - 启动算法备案（如使用境外模型，备案路径更复杂）
  - 或：切到国产合规通道（火山 / 阿里通义）作为主路线，反代作备份
- **预计阶段**：Phase 3 启动前
- **风险等级**：高（不备案不能上线 AIGC 类目）

## 5. Web 端 UI 补齐
- **当前决策**：Phase 1 只做 Web 端路由 + 数据模型骨架，UI 完整度等小程序 PMF 后再补
- **触发条件 = 必须回头处理**：
  - 小程序月活 > 1 万 且付费率 > 3%（PMF 信号）
  - 或：用户反复反馈"想在 PC 上传高清图"
- **回头要做**：Web 端 UI 全套补齐，复用后端 API
- **预计阶段**：Phase 5
- **风险等级**：低

## 6. 小程序主体升级（ADR-006）
- **当前决策**：MVP 阶段以个人主体注册
- **触发条件 = 必须回头处理**：
  - 类目审核被拒且差异点明确指向主体类型
  - 或：月入达到目标下限的 50%（约 3000 RMB/月）
  - 或：用户量 > 1000 且付费需求强烈
  - 或：广告联盟 / 微信支付变现链路被卡死
- **回头要做**：升级到个体工商户（首选）或企业主体；重新走类目申请；可能需要算法备案
- **预计阶段**：Phase 4 末 / Phase 5 初
- **风险等级**：中高（影响多条变现路径）
