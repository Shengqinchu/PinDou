## 背景
ADR-004 锁定小红书是冷启动唯一主渠道，但具体打法需要数据驱动。同时 ADR-003 的定价（9.9 / 28 / 99）需要竞品锚定。

## 目标
两份报告：
1. 主要竞品的免费额度、付费档位、可估算的转化率
2. 小红书拼豆账号的内容策略、互动数据、订单线索

---

## 调研对象

### 第一部分：竞品商业模型
对应任务 A 已调研的小程序 + Web 工具，**专注变现侧**：

每个产品调研：
- 免费用户每天 / 每月能用多少次
- 付费档位（单价 / 月卡 / 包年）
- 是否有广告（激励视频 / banner）
- 是否有人工服务（外包 / 自营高客单）
- 用户在第三方平台的评价（应用宝评论、知乎吐槽、小红书提及）
- 可估算的付费转化率（如有公开数据；否则从评论数 / 下载量推断）

输出：`01_research/competitor/business_models.md`

### 第二部分：小红书账号矩阵
找出当前活跃的拼豆图纸相关账号，至少覆盖：
- 云朵豆原创图纸
- 一粒像素豆
- 主搜索关键词："拼豆图纸"、"拼豆人像"、"宠物拼豆"、"情侣拼豆" Top 20 账号

每个账号调研：
- 账号名 / ID / 链接
- 粉丝数 / 笔记数 / 平均互动数
- 内容定位（教程 / 接单 / 作品展示 / 拼豆开箱）
- 接单模式（私信 / 评论引导 / 小程序跳转）
- 价格档位（如可见）
- 爆款笔记（Top 3，附标题 + 数据）
- 引流路径（小程序入口 / 微信 / 抖音同步？）

输出：`01_research/competitor/xhs_accounts.md`

---

## 衍生输出：增长 Playbook 初稿
基于上面两份调研，提取一份"我们能借鉴 / 必须差异化"的内容：
- 哪种内容形式互动最高（步骤拆解教程 / 成品对比图 / 客户晒图）
- 标题套路（看具体哪些字会被算法推）
- 引流路径（小程序入口 / 私信 / 加 V）
- **小红书合规边界**（哪种引流话术容易封号——交叉看任务 F）
- **我们的差异化卖点**（人像 AI 预处理）能不能编出 5 个内容点

输出：`08_growth/xhs_playbook.md`

---

## 注意事项
- 抓取小红书数据要走**公开 API / 浏览器手动记录**，不要做大规模爬虫（违反小红书 ToS + 易封号）
- 抓取数据样本量小没关系，**数据质量 > 数量**
- 不要保存任何账号主的私人信息（电话 / 微信号 / 地址）
- 引流方式调研只看**他们怎么做的**，不要尝试照搬到我们账号上（合规边界看任务 F）
