# PinDou 项目章程

> 一页纸：目标 / 范围 / 里程碑 / 风险 / 角色。所有人开工前必读。

## 一句话定位
**专攻人像 / 宠物 / 情侣照的 AI 拼豆图纸生成器**。微信小程序优先，Web 端预埋。

## 差异化
市面拼豆工具数十款，但对真实人像普遍失真。根因不是"没用 AI"，而是脚本量化（K-means + RGB 最近邻）缺乏：感知色差（CIELAB + ΔE）、抖动算法、语义理解、智能下采样。

我们的差异化 = **AI 预处理 + 智能量化 + 可手工编辑** 三段式架构。

## 商业目标
副业现金流，**6,000–10,000 RMB/月**。
变现路径：免费 3 次 + 激励视频续次 + AI 高级风格化付费 + 人工精修高客单（详见 ADR-003）。

## MVP 范围（做）
- 上传图片 → AI 风格化预处理 → 智能量化 → 输出图纸 + 材料清单 + 估价 + 简单手动编辑
- 四个风格预设：写实人像 / Q 版人像 / 宠物 / 通用卡通
- 双色卡：MARD + COCO（ADR-002）
- 小程序原生分享 / 保存
- 用户作品集页（强化"成就感"）

## MVP 不做（Phase 1 之后）
复杂图层、实时协作、自有色卡、3D 立体、社区。

## 工作流（必须留痕）
- 决策走 ADR 模板 → `04_architecture/ADRs/`
- 每周周报 → `00_meta/weekly/YYYY-Www.md`
- 外部数据源 → `00_meta/data_sources.md`
- Codex / Gemini 产出物合并前必经 chat 端 Claude 评审，意见归档
- Git 每阶段一个分支，合并 main 前 review
