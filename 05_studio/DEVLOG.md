# Studio 开发记录

## 2026-09-14：商品图片与栏目入场

用户要求其他栏目与首页动效融合，并授权图片优化测试和部署。

- 问题：列表直接读取大原图，原生懒加载范围过宽；其他栏目初次直达无入口动画，查询参数切换反而触发页面淡入。
- 修改：三档独立预览、长期缓存、视区加载与有预算的意图/空闲预读；共享栏目入场，保留首页动画、表单状态、即时点击和访客动态偏好。
- 验证：构建与 90 项后端检查，两浏览器加载/缓存/动效/中断回归，后台换图，以及原有商品与购物车专项。
- 实验：相同 8 Mbps / 150 ms 模拟条件，B 系列可见 8 图 711,330 B → 214,728 B，冷切换中位 1,528 ms → 591 ms。预读后 21 ms，点击前的预读时间另计。
