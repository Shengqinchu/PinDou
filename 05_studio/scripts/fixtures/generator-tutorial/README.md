# Kitty tutorial example

The owner explicitly selected the red-bow Kitty holding a heart in the 2026-09-11 screenshots. The source and saved pattern were matched by the exact 104×104 grid, 6,062 beads and five-colour counts (H2 2532, H7 2412, F5 795, C20 310, A8 13).

These are the original source and original generated preview, not a reconstructed screenshot. `kitty-pattern.json` contains only palette and grid data; no account, session or customer information. Preparation expands the compact colour codes for the isolated screenshot fixture. Run `prepare-generator-tutorial.py`, then the local generator QA server and `capture-generator-tutorial.mjs` to update the Chinese and English panels together. The screenshots use Standard mode and 104×104 throughout; no production generation or paid request is made.
