# 小红书增长 Playbook 初稿

> 版本：Phase 0 draft  
> 日期：2026-05-24  
> 依赖：Task E 公开竞品调研；合规红线待 Task F 复核。

## 高互动内容形式

1. **成品对比**：原图 -> 图纸 -> 摆豆 -> 熨烫后，适合人像 / 宠物验证“像不像”。
2. **翻车复盘**：熨烫失败、颜色碎、五官糊，评论天然会给建议。
3. **大工程震撼**：几万粒、连续 N 天、分板拼接，强收藏。
4. **新手避坑**：买豆、色号、熨烫、工具清单，搜索流量强。
5. **情绪价值**：下班后离线、治愈、成就感、送礼故事。

## 标题套路

- 一张照片真的能变成拼豆吗？
- 宠物照转拼豆，最怕的不是像素化
- 情侣照做成拼豆前，我先试了 3 个版本
- 拼豆新手别直接烫，先看这 5 个坑
- 100x100 和 150x150，人像差别有多大？

## PinDou 差异化内容点

- 人像不像本人：普通量化 vs AI 预处理 vs 手工精修三图对照。
- 宠物毛色不糊：深色宠物、白色宠物、花色宠物专门案例。
- 情侣照不变脸：双人脸型、肤色、衣服色块分离。
- 色卡真实成本：MARD / COCO 一键材料清单 + 估价。
- 可制作性评分：颜色数、碎色块、底板数、预计耗时。
- 失败救援：上传翻车图，给“降色 / 去背景 / 重排五官”方案。
- 送礼场景：生日、纪念日、毕业、宠物纪念。

## 合规边界（待 Task F 复核）

- 不在标题、正文、评论、图片水印里放微信号、手机号、二维码、外链或暗语导流。
- 不建议“私信加 V / 进群拿图纸 / 站外付款”这类路径。
- 可做平台内合规 CTA：关注后续、收藏参数、评论交流尺寸 / 色卡。
- 使用小红书允许的小程序 / 店铺 / 留资组件前先等 Task F 确认。
- 商业合作内容需考虑蒲公英 / 专业号 / 店铺等官方机制。
